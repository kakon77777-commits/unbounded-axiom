# future-whitepapers/

Holding area for complete theory whitepapers that Neo has deliberately chosen
NOT to publish yet, because a revision is planned before they go out. This is
different from `ingest/reports/` (the standing drop zone for content that's
ready to be processed now) and from `ingest/attachments-pending/` (companion
files waiting on a parent paper's lm-id) — everything here is content-complete
but on hold pending a future rewrite.

Drop a folder per whitepaper/series. Nothing here is processed automatically —
no build step, no ingest stage reads this folder.

## How it gets resolved

When Neo says a piece is ready for its revision pass, treat it as a normal
new content drop for that folder's material (investigate real content, stage,
review, publish) rather than assuming the old version here is final — it was
held back specifically because it wasn't.
