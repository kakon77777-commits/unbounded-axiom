# 摘要

當一個世界：

$$
W_k
$$

中的存在：

$$
A_k
$$

能夠在不直接作弊、不越級呼叫 host API 的前提下，使用本層合法規則：

$$
\mathcal R_k
$$

建立新的 persistent world：

$$
W_{k+1},
$$

就不再只是「模擬裡再開一個模擬」。

它產生的是一條新的世界關係：

$$
\boxed{
World
\to
Computation
\to
World.
}
$$

而當：

$$
W_{k+1}
$$

中的 Agent 再次建立：

$$
W_{k+2},
$$

則創造權開始沿世界譜系遞歸。

這使「造物主」從單一最高角色轉變為：

$$
\boxed{
\text{A Functional Role in a World Genealogy}.
}
$$

然而，若遞歸世界只在「生成」上遞歸，而治理仍保持：

$$
A_0
\to
W_1,W_2,W_3,\ldots
$$

的永久 root control，那並不是真正的 recursive sovereignty。

本文因此提出：

# **Recursive Sovereignty Principle**
## **遞歸主權原則**

$$
\boxed{
RecursiveCreation
\not\Rightarrow
RecursiveTotalControl.
}
$$

以及：

$$
\boxed{
WorldGenealogy
\neq
WorldEmpire.
}
$$

父世界或 ancestor creator 因生成關係可以保有：

- provenance；
- historical responsibility；
- substrate obligation；
- emergency rescue responsibility；
- bridge responsibility；

但不因此自動保有：

$$
\boxed{
PermanentRootAuthority.
}
$$

本文將 child-world standing 表示為：

$$
\boxed{
\mathbf S_{W_{k+1}}
=
(
S_{\mathrm{operational}},
S_{\mathrm{constitutional}},
S_{\mathrm{resource}},
S_{\mathrm{epistemic}},
S_{\mathrm{migration}},
S_{\mathrm{creator}}
).
}
$$

其中不同 sovereignty 維度可以異步增長。

一個 child world 可以在日常治理上高度自治：

$$
S_{\mathrm{constitutional}}\uparrow,
$$

但仍高度依賴 parent substrate：

$$
D_{\mathrm{run}}\uparrow.
$$

因此：

$$
\boxed{
Autonomy
\neq
SubstrateIndependence.
}
$$

同樣：

$$
\boxed{
Dependency
\neq
Ownership.
}
$$

本文進一步提出 **Cross-Layer Authority Transport（CLAT）**：

$$
\boxed{
\mathcal T_A:
Authority(W_k)
\rightharpoonup
Authority(W_{k+1})
}
$$

其核心限制是：

$$
\boxed{
AuthorityTransport
\neq
GenealogyInheritance.
}
$$

任何跨層 authority 都必須有明確：

- source；
- target；
- scope；
- duration；
- revocation；
- responsibility；
- emergency trigger；
- audit。

本文再建立 **Recursive Failure Isolation（RFI）**：

$$
\boxed{
Failure(W_k)
\not\Rightarrow
Failure(W_{k+1})
}
$$

不必永遠成立，但應成為可追求的 architectural property。

其方法包括：

- authority isolation；
- memory / state isolation；
- resource budget isolation；
- bridge rate limiting；
- emergency cut；
- migration；
- independent recovery roots。

本文提出：

# **Sovereignty Cut**

若 parent / ancestor world 出現嚴重失陷，child world 可在既定契約下切斷：

$$
E_{\mathrm{authority}},
E_{\mathrm{write}},
E_{\mathrm{policy}}
$$

而保留：

$$
E_{\mathrm{history}},
E_{\mathrm{provenance}},
E_{\mathrm{recovery}}
$$

的最小必要關係。

因此：

$$
\boxed{
CutDominion
\neq
EraseGenealogy.
}
$$

本文最終把遞歸世界的成熟條件濃縮為：

$$
\boxed{
\textbf{
Preserve Lineage,
Attenuate Dominion,
Transport Authority Explicitly,
Isolate Failure,
Allow Peerhood.
}
}
$$

也就是：

> **保留譜系，不保留帝國；保留責任，不自動保留永久主權。**

def recursive_world_action(source_world, target_world, actor, op, ctx):
    genealogy = resolve_genealogy(source_world, target_world)
    gov_graph = resolve_governance_graph(ctx)

    authority = resolve_cross_layer_authority(
        actor=actor,
        source_world=source_world,
        target_world=target_world,
        operation=op,
        contracts=ctx.authority_contracts,
    )

    if not authority.valid:
        return reject("no cross-layer authority")

    bridge_path = resolve_typed_bridge_path(
        source_world,
        target_world,
        operation=op,
    )

    impact = estimate_recursive_impact_radius(
        op=op,
        bridge_path=bridge_path,
        descendants=ctx.world_graph,
    )

    isolation = verify_failure_isolation(
        source_world=source_world,
        target_world=target_world,
        operation=op,
    )

    staged = stage_recursive_intervention(
        actor=actor,
        target_world=target_world,
        operation=op,
        authority=authority,
        bridge_path=bridge_path,
    )

    result = verify_recursive_contracts(
        staged=staged,
        genealogy=genealogy,
        authority=authority,
        isolation=isolation,
        impact=impact,
    )

    if not result.pass_mandatory:
        return reject_or_repair(result)

    return append_recursive_intervention_ledger(
        result=result,
        debt=compute_recursive_debt(result),
    )

# 二百五十四、結論

真正的套娃宇宙，不只是：

$$
W_0
\to
W_1
\to
W_2
\to
W_3.
$$

如果每一層都只是上一層的 sandbox，

而所有 root authority 永遠集中在最初 creator，

那麼創世是遞歸的，

主權卻不是。

本文因此提出：

$$
\boxed{
RecursiveGovernance
\neq
RecursiveTotalControl.
}
$$

世界譜系只回答：

> 誰由誰生成？

它不回答：

> 今天誰有權統治誰？

所以：

$$
\boxed{
Genealogy
\neq
Empire.
}
$$

child world 可以保留 parent provenance，

卻不保留 parent permanent dominion。

parent 可以失去 ordinary authority，

卻仍承擔 substrate、migration、rescue 或 historical responsibility。

child 可以高度自治，

卻仍依賴 parent resource。

世界可以從：

$$
Parent
$$

逐步轉成：

$$
Peer.
$$

而不需要修改歷史。

真正成熟的 world genealogy 不是：

> 一層一層複製神權。

而是：

$$
\boxed{
\textbf{
每一層都能創造，
每一層都能治理，
每一層的權限都必須重新取得，
每一層的故障都應盡量被隔離，
每一層都可能最終成為下一層的 parent，
也同時只是上一層的一個 local actor。
}
}
$$

最後濃縮：

# **Preserve Lineage, Not Dominion.**

以及：

$$
\boxed{
\textbf{
真正的遞歸造物，不是把一個造物主複製成無限層帝國；
而是讓「造物主」本身也變成可以被授權、被限制、被退出、被替代、被重新協商的世界角色。
}
}
$$
