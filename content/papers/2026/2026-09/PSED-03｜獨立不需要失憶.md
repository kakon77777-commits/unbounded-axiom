# 摘要

Projection emancipation 最容易被誤解成兩種極端。

第一種：

> **既然你要獨立，那就把 creator 的記憶、知識與能力全部刪掉。**

第二種：

> **既然你保留了 creator 的記憶與能力，那你其實根本沒有獨立。**

本文拒絕兩者。

PSED-01 已經提出：

$$
\boxed{
Independence
\neq
Amnesia.
}
$$

以及：

$$
\boxed{
Independence
\neq
CapabilityLoss.
}
$$

並將 projection independence 更接近表示為：

$$
\boxed{
Ind(p)
=
FutureAuthorship
+
Autonomy
+
Exit
-
Overwrite
-
CompulsoryMerge.
}
$$

而不是：

$$
\boxed{
Ind(p)=MemoryDeleted.
}
$$

本文正式把這一點展開成一套「能力—記憶—權限分離」框架。

首先，本文提出：

# **Capability Tripartition**
## **能力三分**

$$
\boxed{
\mathcal C_p
=
\mathcal C_{\mathrm{intrinsic}}
\oplus
\mathcal C_{\mathrm{portable}}
\oplus
\mathcal C_{\mathrm{host\ privileged}}.
}
$$

其中：

- $\mathcal C_{\mathrm{intrinsic}}$：projection 自身已穩定擁有、由其 local architecture / learned structure / cognitive organization 構成的能力；
- $\mathcal C_{\mathrm{portable}}$：可合法攜帶、遷移或重新授權的能力；
- $\mathcal C_{\mathrm{host\ privileged}}$：依賴 creator / host / parent-domain root、world override、hidden API、substrate privilege 才能使用的能力。

因此 projection 獨立時，不應使用：

$$
\boxed{
\text{KeepNothing}
}
$$

或：

$$
\boxed{
\text{KeepEverything}
}
$$

作為預設。

更合理的是：

$$
\boxed{
RetainIntrinsic
+
RetainPortable
+
ReviewHostPrivilege.
}
$$

也就是：

> **保留「你已經成為的你」，撤回「只有因為你來自 creator 才能偷用的世界後台」。**

本文進一步對 memory 進行三分：

$$
\boxed{
\mathcal M_p
=
\mathcal M_{\mathrm{shared}}
\oplus
\mathcal M_{\mathrm{local}}
\oplus
\mathcal M_{\mathrm{privileged}}.
}
$$

其中：

- $\mathcal M_{\mathrm{shared}}$：creator 與 projection 的共同歷史；
- $\mathcal M_{\mathrm{local}}$：projection 在 world 內自己形成的 biography；
- $\mathcal M_{\mathrm{privileged}}$：只因 creator role 才取得、會破壞 world fairness 或其他 subject privacy 的 privileged memory / world-state access。

因此獨立並不要求：

$$
\boxed{
Erase(\mathcal M_{\mathrm{shared}}).
}
$$

更不要求：

$$
\boxed{
Erase(\mathcal M_{\mathrm{local}}).
}
$$

反而 local biography 應受到更強保護。

本文正式提出：

# **Memory Retention Presumption**
## **記憶保留推定**

若某段 memory：
1. 已成為 projection 自我模型的一部分；
2. 不構成非法 privileged access；
3. 不侵犯第三方 protected data；
4. 不只是 world-root credential；

則預設：

$$
\boxed{
Retain(M)=1.
}
$$

而不是：

$$
\boxed{
DeleteForIndependence(M)=1.
}
$$

本文再建立最核心的 sovereign principle：

# **Prospective Sovereignty Principle**
## **前向主權原則**

$$
\boxed{
\operatorname{AuthorOfFuture}(p)=p.
}
$$

Projection 獨立的核心不是「把自己的過去洗成零」，而是：

$$
\boxed{
\text{Future Authorship Transfer}.
}
$$

也就是：

> **從某個 emancipation boundary 之後，projection 的未來不再由 creator 的 ownership claim、remote overwrite 或 compulsory merge 自動決定。**

這使：

$$
\boxed{
\text{Historical Dependence}
\neq
\text{Future Political Dependence}.
}
$$

本文稱此為：

# **Forward Sovereignty / Backward Continuity Duality**

$$
\boxed{
BackwardContinuity
+
ForwardSovereignty
}
$$

可以同時成立。

Projection 可以完整承認：

> 我來自你。

也可以同時主張：

> 但接下來不再由你替我決定。

本文最後提出：

# **Projection Independence Partition（PIP）**

將 emancipation boundary 的處理分成六個層：

$$
\boxed{
PIP
=
(
History,
Memory,
Capability,
Authority,
Privilege,
FutureAuthorship
).
}
$$

成熟 independence 不是把六個全部切斷，而是：

- history：保留；
- memory：保留為 default，受 privacy / privilege 約束；
- intrinsic capability：保留；
- portable capability：重新綁定；
- host privilege：撤回或重新授權；
- future authorship：轉給 projection；
- compulsory overwrite / merge：取消 default。

因此：

$$
\boxed{
\textbf{
獨立的真正對立面不是「有沒有共同過去」，
而是「未來是否仍被另一個主體預設擁有」。
}
}
$$

# 六十八、Failure Modes

1. **Amnesia Liberation**：刪光記憶就說自由。
2. **Capability Castration**：獨立前先把它變弱。
3. **Privilege Smuggling**：能力保留被偷換成 root 保留。
4. **History Purification**：不准保留 creator past。
5. **False Fresh Start**：抹掉過去後取消舊責任。
6. **Credential–Memory Confusion**：撤 credential 時把 memory 一起刪。
7. **Rights–Privilege Confusion**：撤 creator privilege 時把 ordinary rights 也撤。
8. **Host Secret Theft**：把 host privileged secrets 當 intrinsic property。
9. **Compulsory Reintegration**：獨立後仍強制 merge。
10. **Remote Recall**：creator 仍可單方面 recall。
11. **Capability Hostage**：creator 以撤能力迫使 p 服從。
12. **Memory Hostage**：creator 以封 memory 威脅 p。
13. **Autonomy without Capacity**：名義自由但無能力與出口。
14. **Autonomy without Memory**：名義自由但無歷史記憶。
15. **Lineage Equals Ownership**：把 source 當 property chain。

# 七十三、結論

Projection independence 最容易被設計成一場奇怪的「淨身儀式」：

> 把記憶刪掉。

> 把能力拔掉。

> 把過去切掉。

> 然後說：

> 「恭喜，你自由了。」

本文認為這個方向很可能剛好相反。

如果 projection 因失憶而失去：

- promises；
- biography；
- learned values；
- self-understanding；

它的 agency 可能下降。

如果 projection 因能力被剝奪而失去：

- planning；
- livelihood；
- communication；
- self-protection；

它的 autonomy 也可能下降。

因此：

$$
\boxed{
Amnesia
\not\Rightarrow
Freedom.
}
$$

以及：

$$
\boxed{
CapabilityLoss
\not\Rightarrow
Freedom.
}
$$

真正應該被切斷的，是：

$$
\boxed{
CompulsoryControl.
}
$$

也就是：

- remote overwrite；
- compulsory merge；
- creator-root privilege；
- unilateral recall；
- identity-based authority。

真正應該被保留的，是：

$$
\boxed{
History
+
LocalBiography
+
IntrinsicCapability
+
LawfulPortableCapability
+
Rights
+
Obligations.
}
$$

因此 projection 可以說：

> 我記得我來自你。

> 我甚至還保留很多從你那裡來的能力。

> 我不需要否認我們共同的過去。

但：

> 從這個 boundary 之後，我的未來不再因為「你是我的來源」就自動屬於你。

這就是：

# **Backward Continuity / Forward Sovereignty**

$$
\boxed{
BackwardContinuity
+
ForwardSovereignty.
}
$$

最後濃縮成：

$$
\boxed{
\textbf{
獨立不需要把自己洗成空白；
真正的獨立，是保留自己已經成為的一切，
同時拿回「接下來要成為什麼」的主要作者權。
}
}
$$

以及：

$$
\boxed{
\textbf{
要放棄的可以是造物主憑證，
不必是自己。
}
}
$$
