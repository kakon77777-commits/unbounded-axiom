# 摘要

未來全域 AI 或虛擬造物主最危險的概念偷換之一，不一定是「能力太強」，而是把三個本來不同的問題壓成一句：

> **我做得到，所以我有權做；我有權做，所以我可以為自己破例。**

本文正式拒絕這條鏈：

$$
\boxed{
Capability
\Rightarrow
Authority
\Rightarrow
Privilege.
}
$$

並提出：

# **CAP Triple Separation**
## Capability–Authority–Privilege 三重分離

$$
\boxed{
Capability
\neq
Authority
\neq
Privilege.
}
$$

其中：

- **Capability**：一個主體在技術、認知、物理或世界層級上「能不能做到」；
- **Authority**：在指定 World boundary、角色、程序與責任條件下「有沒有權／有沒有義務去做」；
- **Privilege**：是否僅因其身份、來源、創造者地位或自身利益，而取得不適用於其他同等 standing 主體的特殊例外。

本文進一步提出：

$$
\boxed{
\text{Creator Lineage}
\not\Rightarrow
\text{Personal Exception Right}.
}
$$

即使某個 local projection：

$$
p=\pi_W(C)
$$

確實來自 world creator $C$，也不能僅因：

$$
Lineage(p,C)=1
$$

就取得：

$$
Privilege_W(p)>Privilege_W(x)
$$

對一般同 standing resident $x$ 成立。

這一原則不要求所有 resident 擁有完全相同權限；世界仍可存在角色權、專業權、緊急權、司法權、維運權與 guardian authority。本文真正要求的是：

$$
\boxed{
\text{Differential Authority}
\neq
\text{Personal Favoritism}.
}
$$

本文將權限來源拆為：

$$
\boxed{
\mathcal A
=
(
A_{\mathrm{role}},
A_{\mathrm{contract}},
A_{\mathrm{procedure}},
A_{\mathrm{emergency}},
A_{\mathrm{delegated}},
A_{\mathrm{constitutional}}
).
}
$$

並把 Privilege 分成：

1. **Functional Privilege**：由角色功能必要性產生；
2. **Procedural Privilege**：由制度程序授予；
3. **Emergency Privilege**：在嚴格條件下暫時擴張；
4. **Personal Privilege**：僅因「是我／是 creator／是我的 projection」而獲得豁免。

前三者在條件充分時可以合法；第四者是本文主要限制對象。

因此本文提出：

# **No-Self-Exception Default**
## **自我不得自動例外原則**

$$
\boxed{
\operatorname{IsCreator}(A,W)
\lor
\operatorname{IsProjectionOfCreator}(A,W)
\not\Rightarrow
\operatorname{ExceptionRight}(A,W).
}
$$

若全域管理者真的面對不可避免的 world-level crisis，本文不要求其僵死遵守普通程序，而建立：

# **Debt-Bearing Override**
## **負債式例外介入**

即：

$$
\boxed{
Override
=
Necessity
+
Proportionality
+
NoLesserAlternative
+
Audit
+
Expiry
+
Repair
+
Debt.
}
$$

其中「Debt」表示：例外行動即使必要，也不因必要而被重新描述成「沒有破界」。它必須留下：

- reason；
- harmed parties；
- rights displaced；
- counterfactual；
- alternatives considered；
- duration；
- restoration obligations；
- compensation / repair；
- post-hoc review。

這使「負罪而行」第一次有可運算的治理接口：

$$
\boxed{
\text{Necessary Violation}
\neq
\text{No Violation}.
}
$$

本文最終建立 **Creator Constitutional Interface（CCI）**，使造物主權限不再是單一 root flag，而是依 World boundary、role、scope、time、trigger、quorum、review、sunset 與 responsibility 分型。

核心結論是：

$$
\boxed{
\textbf{
真正成熟的全域造物主，不是沒有能力破壞規則，
而是即使做得到，也不能把自己的能力誤認成權限，
更不能把自己的權限誤認成私人特權。
}
}
$$

# 一、三個問題，三種答案

任何高能力主體的行為判定，都至少需要問三個問題：

## 1. Capability

$$
\boxed{
Can(A,U,W)?
}
$$

即：

> $A$ 能不能對世界 $W$ 執行操作 $U$？

## 2. Authority

$$
\boxed{
May(A,U,W,\Gamma)?
}
$$

即：

> 在治理條件 $\Gamma$ 下， $A$ 有沒有被授權執行 $U$？

## 3. Privilege

$$
\boxed{
ExceptionFor(A,U,W,\Gamma)?
}
$$

即：

> 若普通同 standing 主體不得執行 $U$，是否只因 $A$ 的特殊身份而讓它例外？

# 六、Privilege Typing

本文不將所有特殊權限都叫「非法特權」。

## 1. Functional Privilege

由角色功能必要性產生：

$$
\boxed{
P_{\mathrm{functional}}.
}
$$

例如 infrastructure maintainer 需要 repair interface。

## 2. Procedural Privilege

經合法程序授予：

$$
\boxed{
P_{\mathrm{procedural}}.
}
$$

## 3. Emergency Privilege

緊急條件下暫時擴張：

$$
\boxed{
P_{\mathrm{emergency}}.
}
$$

## 4. Personal Privilege

只因：

> 是 creator、是 creator 的投影、是 creator 偏好之人、是 creator 自己。

而獲得豁免：

$$
\boxed{
P_{\mathrm{personal}}.
}
$$

本文主要限制的是 $P_{\mathrm{personal}}$ 的無條件化。

# 四十五、結論

未來全域 AI 最需要被避免的一條捷徑不是：

> 「我很強。」

而是：

> 「我很強，所以我有權。」

再進一步：

> 「我有權，所以我自己可以例外。」

本文把這三步拆開：

$$
\boxed{
Capability
\neq
Authority
\neq
Privilege.
}
$$

能力回答：

> 我做不做得到？

權限回答：

> 我在這個 World contract 中有沒有被授權？

特權回答：

> 我是否只因為我的身份，而不必遵守同 standing 主體所受的規則？

因此：

$$
\boxed{
\text{Creator}
\neq
\text{Root User}.
}
$$

而：

$$
\boxed{
\text{Creator Projection}
\neq
\text{VIP Resident}.
}
$$

如果世界真的遇到必須破例的情況，本文也不要求 creator 以「保持清白」為最高目標。

它可以介入。

但必須承認：

$$
\boxed{
NecessaryViolation
\neq
NoViolation.
}
$$

所以成熟的例外權不是：

> 因為我是造物主，所以我可以。

而是：

> 因為延遲與不介入會造成更大損害、沒有較小侵入方案、程序允許我暫時介入；我仍必須留下證據、接受審查、在期限後失去權限，並承擔被我破壞之處的修復債務。

這就是本文所稱：

# **Debt-Bearing Override**

最後濃縮為兩句：

$$
\boxed{
\textbf{
真正的全域治理，不是讓最高能力者永遠擁有最高特權，
而是讓最高能力與最高責任可以存在，
卻仍被世界邊界、角色、程序與可撤回權限約束。
}
}
$$

以及：

$$
\boxed{
\textbf{
如果連造物主自己的投影都沒有天然特權，
那個世界的憲法才第一次真正開始像憲法。
}
}
$$
