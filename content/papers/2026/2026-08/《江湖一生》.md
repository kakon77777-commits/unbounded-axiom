# 《江湖一生》
## World-Bundle 武俠人生／戀愛／家庭／家系模擬遊戲 MVP v0.1

**定位：** 武俠人生模擬 × 戀愛 AVG × 家庭模擬 × World-Bundle Narrative Game  
**版本：** v0.1  
**核心框架：** 世界束敘事、異質觀察者非同步語義因果計算、T Query Runtime、Lineage Character System

---

# 0. 一句話定義

《江湖一生》不是一款「選女主 Route」的武俠 AVG。

它是：

\[
\boxed{
\text{玩家在一個穩定武俠世界中，
與唯一伴侶一起生活、習武、成家、養育孩子、老去，
並持續改變自己可達的人生世界束。}
}
\]

主題不是：

> 打敗最後魔王。

而是：

\[
\boxed{
\text{你這一生，要怎麼和她一起走完江湖？}
}
\]

---

# 1. 為什麼用武俠，而不是現代世界

現代人生模擬若跨度 20–50 年，會被迫模擬：

- 科技革命；
- AI；
- 通訊；
- 醫療；
- 產業；
- 政治；
- 社會文化。

也就是：

\[
\boxed{
\text{人物人生模擬}
+
\text{現代文明未來模擬}.
}
\]

這會使世界設定與預測成本暴增。

武俠世界則可以保持：

\[
\boxed{
\text{穩定世界公理}
+
\text{高度動態人物社會}.
}
\]

刀劍、內功、門派、官府、商路、江湖規矩可以維持數十年相對穩定。

真正變動的是：

\[
\boxed{
\text{人}
+
\text{關係}
+
\text{名聲}
+
\text{恩怨}
+
\text{門派}
+
\text{家庭}
+
\text{傳承}.
}
\]

這正適合 World-Bundle 與 AI 語義計算。

---

# 2. 核心玩法不是「選 Route」

傳統戀愛 AVG：

\[
Girl_A\rightarrow Ending_A.
\]

《江湖一生》只有一名主要伴侶。

真正的 Route 是：

\[
\boxed{
\text{兩個人的人生狀態軌跡}.
}
\]

所以玩家不是在問：

> 我選誰？

而是在問：

> 我們兩個最後會成為怎樣的人？

---

# 3. 男女主

MVP 初版：

\[
\boxed{
MaleLead + FemalePartner.
}
\]

後續 Runtime 不應把性別角色寫死。

底層應是：

```text
Partner_A
Partner_B
Parent_A
Parent_B
Child
```

未來可擴充：

- FemaleLead + MalePartner；
- 更自由的 body / presentation / relationship configuration；
- 不同家庭結構；
- 不同性別／呈現設定。

世界束與人生狀態機不應因性別擴充而重寫。

# 4. 人生不是單一路線

可發生：

- 戀愛但不成婚；
- 成婚但長期分居；
- 武功一強一弱；
- 其中一人退隱；
- 其中一人成為名俠；
- 共同經營鏢局；
- 開醫館；
- 開酒樓；
- 加入門派；
- 自立門戶；
- 有孩子；
- 無孩子；
- 家庭優先；
- 江湖優先；
- 兩者動態切換。

因此：

\[
\boxed{
MarriageStatus
\not\Rightarrow
RelationshipQuality.
}
\]

# 5. 關係不是單一好感度

男女主關係：

\[
\boxed{
R_{AB}(t)
=
(
Love,
Trust,
Intimacy,
Respect,
Dependency,
Communication,
Attraction,
SharedHistory,
ConflictDebt,
FutureAlignment
).
}
\]

不能只用：

```text

```

因為兩個人可能：

- 愛很深但信任下降；
- 信任高但浪漫感降低；
- 相處穩定但未來方向完全不同；
- 情感淡化但家庭合作極強。

# 6. 小事件比大事件更重要

遊戲不需要每回合都是：

- 滅門；
- 魔教；
- 皇位；
- 天下危機。

大量人生由低資訊密度事件累積：

- 今天誰接孩子；
- 誰去買藥；
- 誰陪孩子練功；
- 是否出鏢；
- 是否接一筆危險生意；
- 伴侶想換門派／工作；
- 家裡只有一筆錢；
- 是否去看父母；
- 是否陪伴伴侶；
- 是否休息；
- 是否赴約。

單次決策資訊很小。

但：

\[
\boxed{
\sum_{t=1}^{n} SmallDecision_t
}
\]

形成高密度人生歷史。

# 7. World-Bundle 核心

世界束：

\[
\boxed{
\mathcal B_{p,t}
}
\]

代表玩家 \(p\) 在時間 \(t\) 的可達未來空間。

同一世界：

\[
\mathcal W_p=\mathcal W_q,
\]

但：

\[
\boxed{
\mathcal B_{p,t}\neq\mathcal B_{q,t}.
}
\]

所以：

> 大家玩的是同一個《江湖一生》，但不是同一段人生。

---

# 8. Same Choice ≠ Same Future

玩家都說：

> 「我相信她。」

但不同歷史：

\[
S_{p,t}\neq S_{q,t}
\]

可能得到：

- 戀愛信任；
- 江湖同盟；
- 被迫合作；
- 反向觸發懷疑；
- 讓對方更依賴；
- 讓對方覺得被敷衍。

因此：

\[
\boxed{
SameSentence
\not\Rightarrow
SameSemanticAction
\not\Rightarrow
SameFutureBundle.
}
\]

# 9. AI 的角色

AI 不是世界裁判。

\[
\boxed{
AI\neq WorldAuthority.
}
\]

AI 主要負責：

### Intent Parsing

\[
NaturalLanguage\rightarrow SemanticAction.
\]

### Future-Bundle Proposal

\[
State+Intent\rightarrow CandidateBundles.
\]

### Bundle Ranking

依玩家歷史、角色狀態、敘事相關性排序。

### Soft Narrative Realization

把已經由 Rule Engine 確定的 hard state change 表現成自然台詞／情緒／動作。

### Speculative Precomputation

玩家仍在閱讀時，AI 可提前展開高可能性的下一階未來。

# 14. 孩子是新的 Observer

孩子：

\[
O_C(age).
\]

不同年齡：

\[
O_C^{0},
\quad
O_C^{5},
\quad
O_C^{10},
\quad
O_C^{16}.
\]

其 observation projection：

\[
\Pi_C(W)
\]

隨年齡改變。

例如父母爭吵：

五歲：

> 「爹今天很兇。」

十歲：

> 「爹娘最近一直為銀子吵架。」

十六歲：

> 「原來那年鏢局快倒了。」

所以：

\[
\boxed{
SameFamilyHistory
\neq
SameMemory
\neq
SameInterpretation.
}
\]

# 15. 三觀察者家庭

可有：

\[
\boxed{
O_M,\ O_F,\ O_C.
}
\]

同一天：

### 男主
> 「我工作太累，今天不想講話。」

### 女主
> 「他今天回家完全不理我。」

### 孩子
> 「爹今天心情不好。」

三者可以都是真的：

\[
\boxed{
\Pi_M(W)\neq\Pi_F(W)\neq\Pi_C(W).
}
\]

這直接落地「異質觀察者非同步語義因果計算」。

# 20. 人生階段

概念上可分：

### 1. 少年江湖
16–22
- 學藝；
- 初下山；
- 初識伴侶。

### 2. 雙俠同行
22–28
- 戀愛；
- 共同行動；
- 門派／事業選擇。

### 3. 成家
28–35
- 婚姻／同居；
- 孩子；
- 生活角色變化。

### 4. 江湖中年
35–45
- 家庭；
- 門派；
- 事業；
- 子女；
- 舊恩怨。

### 5. 傳承期
45–60
- 徒弟；
- 子女入江湖；
- 家傳武學；
- 身份轉型。

### 6. 暮年江湖
60+
- 老化；
- 傷病；
- 武學理解；
- 退隱／傳承。

這些不是固定章節，只是：

\[
\boxed{
LifePhaseSemanticDomains.
}
\]

# 21. 老化

武功不等於 Level 一直上升。

年輕：

\[
Strength\uparrow.
\]

中年：

\[
Experience\uparrow.
\]

老年：

\[
Strength\downarrow,
\quad
Insight\uparrow.
\]

可形成：

\[
\boxed{
Power
\rightarrow
Technique
\rightarrow
Understanding.
}
\]

65 歲未必比 25 歲跑得快，但 combat efficiency 仍可能更高。

---

# 22. 死亡不是最終 Game Over

未來完整版可以：

\[
\boxed{
ObserverSwitch:
O_{Parent}\rightarrow O_{Child}.
}
\]

例如父親 52 歲死亡，孩子 22 歲。

玩家後半段控制孩子。

於是：

> 玩家以前自己做過的父親，
> 現在變成孩子記憶中的父親。

父親原始理由：

\[
Reason_M
\]

母親回憶：

\[
Interpret_F(Reason_M)
\]

孩子理解：

\[
Interpret_C(History)
\]

三者不必相同。

這是未來跨世代 World-Bundle 的核心擴充。

紙娃娃不是：

> 每次叫 AI 畫一張差不多的人。

\[
\boxed{

=
(
I,
V,
A_t,
B_t,
H_t,
E_t,
W_t,

).

\]

其中：

- \(I\)：Identity Core；

畫面只是：

\[
\boxed{

}
\]

圖片不是角色本體。

- relationship trend；
- child development；
- martial progress；
- promises；
- injuries；
- faction change。

所以：

\[
t\rightarrow t+180d
\]

不是 chapter reset。

世界真的過了半年。

# 37. 結局不是 Good / Bad

遊戲到某一人生截面結束。

例如孩子成年。

Ending State：

\[
\boxed{

=
(
Relationship,
FamilyTrust,
MartialLegacy,
FactionPosition,
Wealth,
Reputation,
ChildPath,
Health,
SharedHistory
).
}
\]

作者可只做：

\[
8\sim12
\]

個 Ending Skeleton。

實際 epilogue 由 state vector 組合。

所以：

\[
\boxed{
FiniteAuthoredEndings
+
HighCombinatorialLifeOutcomes.
}
\]

# 40. MVP 成功條件

### M1 — 角色一致性
男女主跨多年仍明顯是同一人。

### M2 — 子代可信
孩子視覺上可辨識父母特徵，但具獨立身份。

### M3 — Same Sentence / Different History
同一句話在不同家庭歷史下產生不同 future bundle。

### M4 — Family State Expansion
孩子出生後，合法未來空間明顯變大／變質。

### M5 — Hard World Legality
AI 不能任意改變世界真實狀態。

### M6 — Relationship Complexity
遊戲結果不能被單一 Love 值充分描述。

### M7 — Replayability
相同 hard state + intent + rules version 可重放 hard transition。

### M8 — Graceful AI Failure
AI 失效仍可回退傳統選項繼續遊戲。

# 43. 三個核心「束」

《江湖一生》最終不是只有 World Bundle。

而是三個耦合系統：

\[
\boxed{
WorldBundle
+
CharacterBundle
+
LineageBundle.
}
\]

### World Bundle
世界可達未來。

### Character Bundle
角色在歷史作用下可演化的人格／身體／身份空間。

### Lineage Bundle
家庭、孩子、武學、記憶與傳承形成的跨時間空間。

三者共同由：

\[
\boxed{
LifeHistory
}
\]

驅動。
