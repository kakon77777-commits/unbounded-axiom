# 關聯拓撲與全域黏合
## 閉路、缺陷荷、分支與局部—全域一致性

## 摘要

本文是《動態知識空間論》（DEST）的第四篇子理論，專門處理 DEST-03 中的路徑／拓撲 Gap：

\[
G^P.
\]

前篇已指出，某些研究失敗不是因為缺少節點、缺少資料或缺少單條關係，而是因為局部結果在組合後無法形成全域一致結構。即使：

\[
\rho^N\approx1,
\qquad
\rho^R\approx1,
\]

仍可能因 overlap mismatch、non-commuting transition、closed-loop drift、cycle inconsistency、incompatible branch、version merge failure 或 local-to-global obstruction，使：

\[
D^{\mathrm{global}}
\]

無法通過。

本文建立五級一致性階梯：

\[
\boxed{
\text{Node}
\rightarrow
\text{Overlap}
\rightarrow
\text{Cocycle}
\rightarrow
\text{Cycle}
\rightarrow
\text{Global}.
}
\]

令：

\[
X=\bigcup_{i\in I}U_i,
\]

局部區域具有：

\[
s_i\in\mathcal F(U_i),
\]

重疊具有 typed transition：

\[
g_{ij}:
\mathcal F(U_i)|_{U_i\cap U_j}
\to
\mathcal F(U_j)|_{U_i\cap U_j}.
\]

三重重疊需檢查：

\[
g_{ik}
\stackrel{?}{=}
g_{jk}\circ g_{ij},
\]

閉路：

\[
\gamma:
U_{i_0}\to\cdots\to U_{i_m}=U_{i_0}
\]

則定義 cycle transport：

\[
H_\gamma
=
g_{i_{m-1}i_m}\circ\cdots\circ g_{i_0i_1}.
\]

若：

\[
H_\gamma\neq\operatorname{id},
\]

則存在非平凡 path defect。

本文定義缺陷荷：

\[
\delta_\gamma
=
d_\pi(H_\gamma(s),s),
\]

以及多型別缺陷向量：

\[
\mathbf q_\gamma
=
(
q_{\mathrm{semantic}},
q_{\mathrm{logical}},
q_{\mathrm{condition}},
q_{\mathrm{version}},
q_{\mathrm{source}},
q_{\mathrm{permission}},
q_{\mathrm{certificate}}
).
\]

本文進一步區分：

1. gauge-removable defect；
2. structural defect；
3. branch obstruction；
4. formal cohomological obstruction candidate；
5. 尚未具有足夠後端結構的一般 global-section failure。

本文不要求所有全域性都壓成唯一單值 global section。當多個合法分支無法無損合併時，允許：

\[
\boxed{\text{Branch-Preserving Globality}}.
\]

總命題為：

\[
\boxed{
\text{Globality}
=
\text{local validity}
+
\text{overlap compatibility}
+
\text{cycle audit}
+
\text{branch discipline}
+
\text{gluing certificate}.
}
\]

# 0. 研究定位與非主張聲明

本文不是完整 sheaf theory 教科書，也不宣稱所有語義系統天然形成 sheaf。本文不把所有閉路偏差都自由稱作 holonomy class，更不把任何 global failure 直接升格成：

\[
H^1\neq0.
\]

一般 DEST 只保留：

- overlap defect；
- cocycle defect；
- cycle transport defect；
- global-section failure；
- branch obstruction。

只有 formal backend 通過資格檢查，才允許使用 cohomological obstruction 語言。

---

# 1. 關聯底空間與 Cover

令：

\[
X
\]

為任務相對的關聯底空間。其點可代表命題、參數區域、模型、語言、Agent、工具、版本、學科、proof regime、資料分片或記憶分區。

令：

\[
\mathcal U=\{U_i\}_{i\in I},
\qquad
X=\bigcup_iU_i.
\]

\(\mathcal U\) 是分析 cover，不預設唯一。

若：

\[
\mathcal V\prec\mathcal U
\]

為 refinement，細化可能暴露原本不可見的局部衝突，也可能讓過粗分類製造的假缺陷消失。

因此 defect 必須追蹤：

\[
\operatorname{Persistence}(g\mid\mathcal U\to\mathcal V).
\]

---

# 2. 局部截面

對：

\[
U_i,
\]

設：

\[
\mathcal F(U_i)
\]

為局部狀態空間，選：

\[
s_i\in\mathcal F(U_i).
\]

\(s_i\) 可代表局部 theorem、局部定義、Agent 內部表示、版本狀態、資料融合結果或局部模型。

即使：

\[
\forall i,\quad
\operatorname{LocalCert}(s_i)=\mathsf{Pass},
\]

仍不推出存在：

\[
s\in\mathcal F(X)
\]

使：

\[
s|_{U_i}=s_i.
\]

---

# 3. 過渡映射

若：

\[
U_i\cap U_j\neq\varnothing,
\]

定義：

\[
g_{ij}:
\mathcal F(U_i)|_{U_i\cap U_j}
\to
\mathcal F(U_j)|_{U_i\cap U_j}.
\]

它可為翻譯、座標變換、型別轉譯、schema mapping、model adapter、proof transport、version migration 或 semantic alignment。

每個 \(g_{ij}\) 必須保存：

\[
\operatorname{Dom},\operatorname{Cod},\Theta,\operatorname{Type},\operatorname{Cert}.
\]

一般不預設：

\[
g_{ij}^{-1}
\]

存在，因此 DEST 關聯拓撲允許 directed / non-invertible transport。

---

# 4. 五級一致性階梯

定義：

\[
\mathcal L_C=(C_0,C_1,C_2,C_3,C_4).
\]

## \(C_0\)：Local Validity

\[
\operatorname{LocalCert}(s_i)=\mathsf{Pass}.
\]

## \(C_1\)：Overlap Compatibility

在：

\[
U_{ij}=U_i\cap U_j
\]

要求：

\[
d_{ij}
\left(
s_j|_{U_{ij}},
g_{ij}(s_i|_{U_{ij}})
\right)
\le\varepsilon_{ij}.
\]

exact backend 取：

\[
\varepsilon_{ij}=0.
\]

## \(C_2\)：Cocycle Compatibility

三重重疊上：

\[
g_{ik}
\stackrel{?}{=}
g_{jk}\circ g_{ij}.
\]

## \(C_3\)：Cycle Consistency

對 required cycle：

\[
H_\gamma
\stackrel{?}{\approx}
\operatorname{id}.
\]

## \(C_4\)：Global Gluing

存在 strict、conditional、branch-preserving 或合法 atlas globality。

因此：

\[
C_0\not\Rightarrow C_1
\not\Rightarrow C_2
\not\Rightarrow C_3
\not\Rightarrow C_4.
\]

---

# 5. Pairwise 正確不夠

設：

\[
A\to B,\quad B\to C,\quad A\to C.
\]

即使三條邊 individually legal，也可能：

\[
g_{AC}
\neq
g_{BC}\circ g_{AB}.
\]

因此：

\[
\boxed{
\text{edge-valid}
\not\Rightarrow
\text{triangle-consistent}.
}
\]

---

# 6. Cycle Transport

對閉路：

\[
\gamma=(i_0,i_1,\ldots,i_m=i_0),
\]

定義：

\[
\boxed{
H_\gamma
=
g_{i_{m-1}i_m}
\circ\cdots\circ
g_{i_0i_1}.
}
\]

本文一般稱 cycle transport operator。只有後端真的具有 connection／bundle／group-valued transport 結構時，才嚴格稱幾何 holonomy。

若：

\[
H_\gamma(s)=s
\]

則該狀態閉路一致；若：

\[
H_\gamma(s)\neq s,
\]

則存在 cycle drift。

---

# 7. 缺陷荷

若後端有距離：

\[
d_\pi,
\]

定義：

\[
\boxed{
\delta_\gamma(s)
=
d_\pi(H_\gamma(s),s).
}
\]

更一般保存：

\[
\boxed{
\mathbf q_\gamma
=
(
q_{\mathrm{sem}},
q_{\mathrm{logic}},
q_{\mathrm{cond}},
q_{\mathrm{version}},
q_{\mathrm{prov}},
q_{\mathrm{perm}},
q_{\mathrm{cert}}
).
}
\]

不得預設：

\[
\delta_{\gamma_1\circ\gamma_2}
=
\delta_{\gamma_1}+\delta_{\gamma_2}.
\]

因為 defect 可抵消、放大或非交換。

\mathfrak D_t

- defect count；

# 9. Cycle Basis

完整枚舉所有 cycle 通常不可行。對 graph backend，可選 spanning tree：

\[
T.
\]

每條：

\[
e\in E\setminus T
\]

與 tree path 形成 fundamental cycle。

連通圖基本數量為：

\[
|E|-|V|+1.
\]

但若 transition composition 非交換，普通線性 cycle-space basis 不保證足以替代所有 closed-walk audit，因此 Runtime 必須保存：

```yaml
cycle_backend:
  algebra: abelian|nonabelian|unknown
  basis_complete_for_requested_invariant: true|false|unknown
```

---

# 10. Gauge-like Relabeling

對每個區域選可逆：

\[
h_i,
\]

更新：

\[
\boxed{
g'_{ij}
=
h_j\circ g_{ij}\circ h_i^{-1}.
}
\]

若存在 \(\{h_i\}\) 使所有必要閉路：

\[
H'_\gamma=\operatorname{id},
\]

則標：

\[
\mathsf{GaugeRemovable}.
\]

若任何合法局部重標記都不能移除，標：

\[
\mathsf{StructuralDefect}.
\]

這仍不自動等於某拓撲不變量非零。

---

# 11. Cover Artifact

過粗 cover 可能把不同 regime 塞進同一 \(U_i\)，製造假衝突。

可細化：

\[
U_i
\rightsquigarrow
\{U_i^{(1)},U_i^{(2)}\}.
\]

若 defect 消失，標：

\[
\mathsf{CoverArtifact}.
\]

過細 cover 也會增加 transition、bridge 與 audit 成本。因此 cover selection 本身是優化問題。

---

# 12. 缺失橋接

若：

\[
A\not\to C,
\]

可能需要新增：

\[
B
\]

使：

\[
A\to B\to C.
\]

Bridge 是 global repair operator，不只是補一條 edge。

---

# 13. 過載概念

若概念 \(c\) 同時扮演多個不相容角色，可拆：

\[
c\mapsto\{c_1,\ldots,c_k\}.
\]

並以 explicit transition 保留它們的關係。

這比強迫單一 global label 更忠實。

---

# 14. Branch Obstruction

若：

\[
s^{(1)},s^{(2)}
\]

均合法，但：

\[
s^{(1)}\neq s^{(2)}
\]

且不存在合法 quotient／equivalence 無損識別，則 strict single-valued globality 失敗。

不得為了方便任意刪除其中一個 branch。

---

# 15. Branch-Preserving Globality

若存在合法 global branches：

\[
\{s^{(b)}\}_{b\in B},
\]

以及 branch transition／分離規則：

\[
\mathcal T_B,
\]

定義：

\[
\boxed{
\mathfrak G_B
=
(
\{s^{(b)}\}_{b\in B},
\mathcal T_B,
\mathcal H_B
).
}
\]

它要求 branch 條件明確、branch 內部一致、差異可追蹤、沒有偷換定義，也不能在任務明確需要單值決策時假裝已完成。

# 18. Global Section Search

目標是尋找：

\[
s\in\mathcal F(X)
\]

使：

\[
s|_{U_i}\sim s_i.
\]

exact backend：

\[
s|_{U_i}=s_i.
\]

approximate backend：

\[
d_i(s|_{U_i},s_i)\le\varepsilon_i.
\]

approximate globality 不得冒充 exact globality。

# 19. Consistency Radius Backend

對 pseudometric sheaf 類後端，可用 overlap disagreement 建立 consistency radius：

\[
\epsilon(s)
=
\max_{i,j}
d_{ij}
\left(
s_i|_{U_{ij}},
s_j|_{U_{ij}}
\right).
\]

具體公式依後端定義。

可標：

```text
epsilon = 0      exact
epsilon <= tau   tolerance-consistent
epsilon > tau    inconsistent
```

# 20. Global Section Failure 不等於正式不可能

如果：

\[
\operatorname{GlobalSection}=\varnothing
\]

是 Runtime 搜尋結果，至少仍要區分：

- transition 缺失；
- overlap mismatch；
- cocycle failure；
- cycle transport defect；
- branch incompatibility；
- permission mismatch；
- stale version；
- representation loss；
- formal obstruction；
- search incompleteness。

所以：

\[
\boxed{
\text{not found}
\neq
\text{proved nonexistent}.
}
\]

# 21. Obstruction Hierarchy

定義：

\[
\mathcal O_G
=
(O_0,O_1,O_2,O_3,O_4,O_5).
\]

## \(O_0\)：Missing-transition obstruction

需要的：

\[
g_{ij}
\]

不存在。

## \(O_1\)：Pairwise-overlap obstruction

\[
C_1
\]

失敗。

## \(O_2\)：Cocycle obstruction candidate

三重重疊：

\[
g_{ik}
\neq
g_{jk}\circ g_{ij}.
\]

## \(O_3\)：Cycle obstruction

存在：

\[
H_\gamma\neq\operatorname{id}.
\]

## \(O_4\)：Global-section failure

局部資料存在，但沒有合法 global section 被建立。

## \(O_5\)：Formal cohomological obstruction

只有 formal backend 提供：

- sheaf／presheaf；
- 合法 cover；
- coefficient object；
- cochain complex；
- coboundary；
- 必要 exactness / abelian structure；

後，才允許寫：

\[
[\omega]\neq0\in H^k(\cdot).
\]

一般 DEST 不自動升到 \(O_5\)。

# 30. Version Loop Defect

\[
v_1\to v_2\to v_3\to v'_1.
\]

若回滾後：

\[
v'_1\neq v_1
\]

在 critical invariant 上，則存在 version loop drift。

定義：

\[
\delta_\gamma^{\mathrm{version}}
=
d_V(v'_1,v_1).
\]

\[

\to
A_t
\to

\to

\[
M_{t+n}
\]

丟失關鍵條件、來源或未解債務，形成 memory loop defect。

# 33. Permission-induced Non-Reversibility

若 Agent 權限不同：

\[
P_1\neq P_2,
\]

mapping 可能合法刪除資訊。

此時：

\[
H_\gamma\neq\operatorname{id}
\]

不一定是 bug，而可能是 policy-induced non-reversibility。

因此 loop audit 必須綁定：

\[
\Theta^{\mathrm{permission}}.
\]

---

# 34. Lossy-but-Legal Transport

若：

\[
\operatorname{Loss}(g_{ij})>0
\]

但 loss 已明示且任務允許：

\[
\operatorname{Legal}(g_{ij})=\mathsf{Pass},
\]

則不要求所有 cycle exact identity。

可改要求：

\[
H_\gamma\in\mathcal E_\gamma
\]

其中 \(\mathcal E_\gamma\) 是允許誤差／資訊損失類。

---

# 35. Exact 與 Functional Globality

## Exact

\[
H_\gamma=\operatorname{id}.
\]

## Functional

\[
d(H_\gamma(s),s)\le\tau_q
\]

且 critical invariants：

\[
I_k(H_\gamma(s))=I_k(s)
\]

均保存。

這對摘要、壓縮、跨模態轉譯特別重要。

---

# 36. Critical Invariant Set

對任務 \(q\)，定義：

\[
\mathcal I_q
=
\{I_1,\ldots,I_m\}.
\]

Global Glue 不必保存所有表面字串，而要求所有 critical invariants 在合法運輸後一致。

# 68. 結論

成熟知識系統不能只問：

> 每個節點正確嗎？

也不能只問：

> 每條邊合法嗎？

它還必須問：

1. overlap 是否一致？
2. 三重重疊是否可組合？
3. 閉路回返是否漂移？
4. defect 是哪種類型？
5. 是否可由重標記消除？
6. 是否只是 cover artifact？
7. 是否缺 bridge？
8. 是否需要拆過載概念？
9. 是否存在多合法 branch？
10. 是否真的需要唯一 global section？
11. 是否只能形成 atlas globality？
12. 是否已有正式 obstruction certificate？
13. 還是 Runtime 只是尚未找到？
14. 是否是 representation trap？
15. 黏合是否偷偷刪除必要差異？

因此：

\[
\boxed{
\text{Local correctness}
\not\Rightarrow
\text{Global correctness}.
}
\]

更完整地：

\[
\boxed{
\text{Global correctness}
=
\text{local validity}
+
\text{typed transport}
+
\text{cycle discipline}
+
\text{branch discipline}
+
\text{non-collapse}
+
\text{certificate}.
}
\]

真正的全域性不是把所有局部壓成一個整齊答案，而是：

\[
\boxed{
\text{讓所有可合法統一的部分真正統一，}
}
\]

同時：

\[
\boxed{
\text{讓所有不可無損統一的差異被明確保存。}
}
\]
