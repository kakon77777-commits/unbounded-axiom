## 1. 八維畫風坐標

| 軸 | 0 | 100 |
|---|---|---|
| Line→Painterly | 線稿主導 | 厚塗／繪畫主導 |
| Flat→Volumetric | 平面圖形 | 立體／體積 |
| Muted→Saturated | 低飽和 | 高飽和 |
| Minimal→Dense | 極簡 | 超密集 |
| Organic→Industrial | 有機／裝飾 | 工業／機械 |
| Bright→Dark | 明亮 | 黑暗 |
| Stylized→Realist | 高度風格化 | 寫實 |
| Static→Dynamic | 圖標／靜態 | 電影／動勢 |

每位畫師近似成：

$$K_a=(L,V,S,D,I,B,R,M)$$

這只是**風格搜尋座標**，不是藝術史客觀真值，也不能代表創作者所有時期。

# 8. 不用人名的 Prompt 編譯器

推薦結構：

```text
[LINE]
+ [ANATOMY / SHAPE]
+ [COLOR]
+ [LIGHT]
+ [COMPOSITION]
+ [MATERIAL]
+ [DETAIL DENSITY]
+ [MOOD]
+ [MEDIUM]
```

例如「天野附近」：

```text
elongated elegant fantasy figure,
feather-light ink contour,
pale watercolor wash,
soft ivory negative space,
gold accents,
art-nouveau ornamental framing,
ethereal dreamlike mood
```

「新川附近」：

```text
expressive dry ink brush,
broken black contour,
high-contrast monochrome,
military industrial design,
loose splatter texture,
dynamic asymmetrical silhouette,
minimal background
```

「WLOP／阮佳附近但降低 AI 同質感」：

```text
painterly fantasy character,
cinematic atmospheric perspective,
strong but controlled backlight,
ornate coherent costume,
selective edge hierarchy,
mist layers and deep environment,
non-generic facial proportions,
asymmetric silhouette variation
```

# 9. 給 AADS / GAR 的使用方式

Agent 不要問「用誰的風格」，而應：

1. 以人名找到風格座標；
2. 搜尋最近 5–10 個節點；
3. 根據目標把某幾條軸移動 ±10～30；
4. 將結果轉成非人名 Style Recipe；
5. 再由 GAR 找 LoRA / Reference / Model / Control Provider。

例如：

```text
找離「Amano」最近的 6 個節點，
但把 Industrial +25、Dark +15、Painterly +20，
保留低飽和與高裝飾度，
生成 5 套新 Style Recipe，禁止直接使用畫師名。
```

這樣才是真正的「畫風地圖導航」。

# 10. 關於「上岸不上岸」

本表**不以創作者是否商業主流、同人、成人向經歷或跨圈活動作為排除條件**。例如 Tony Taka、RAITA、Asanagi 等仍可以作為視覺研究索引，但資料只保留線條、人體、光影、構圖、材質等中性形式特徵，不記錄露骨內容分類。

# 11. v0.1 邊界

- 這不是全球完整名錄，而是高辨識度導航節點集。
- `nearest_style_neighbors` 是依八維人工分析坐標計算，不代表藝術史影響關係。
- 當代畫師名字適合作分析索引；產品生成建議優先使用 `non_name_prompt`。
- 中國區刻意拆成中國大陸、台灣、香港，保留不同創作生態。
- 後續可擴充日本同人／遊戲原畫、中國網路插畫、韓國遊戲美術、MTG／歐美概念藝術、繪本、怪誕、生物機械等專區。
