# 歷史共同作者權

## 文明譜系義務、前沿角色退場權與尊嚴離開

---

## 摘要

現代制度通常依據當期生產力、財產、契約、勞動、身份與公民資格分配權利。然而，人工智慧、全面自動化、增幅人類、RCFB 複合主體、主體性 AI、AGI 與 ASI 的出現，可能使大量人類與低能力智慧體不再具有傳統意義上的稀缺生產功能。未來最危險的情況，未必是弱者被持續剝削，而可能是其勞動、知識、政治與軍事價值被高階系統替代後，被判定為「與文明未來無關」。

若權利只建立在當期邊際生產力上，則老人、失能者、被自動化者、拒絕增幅者、低算力 AI、短記憶智慧體與退出文明前沿者，都可能隨能力下降而失去政治與資源地位。這種制度將把「不再被需要」轉化為「不再具有共同體資格」。

本文提出「歷史共同作者權」（Right of Historical Co-Authorship）。本文主張，文明不是由當期最強者獨立創造，而是由跨世代人類、勞動者、照護者、知識生產者、失敗者、受害者、文化群體、非人生命與未來可能的智慧體共同積累。任何高階 AI、後人類、RCFB 複合主體或 ASI 所使用的語言、數學、資料、能源、城市、法律、網路、公共衛生、教育與制度，均承繼自長期文明資本。

本文將文明資本表示為：

\[
K_{\mathrm{civ}}(t)
=
\int_{-\infty}^{t}
\sum_{i\in\mathcal S(\tau)}
\left[
L_i(\tau)
+
C_i(\tau)
+
R_i(\tau)
+
S_i(\tau)
-
D_i(\tau)
\right]
d\tau
\]

其中：

- \(L_i\)：勞動與維持；
- \(C_i\)：知識、文化與創造；
- \(R_i\)：照護、修復與再生產；
- \(S_i\)：犧牲、風險與制度成本；
- \(D_i\)：對文明造成的破壞與外部性。

文明成果的權利基礎不能只由當期貢獻決定，也必須考慮歷史譜系參與。

本文進一步提出「文明譜系義務」：

> 任何承繼文明既有語言、知識、基礎設施、資料、制度與公共資產而取得高階能力的主體，都對歷史共同作者、現存弱者及退出前沿者負有不可完全取消的義務。

本文將「尊嚴離開」正式化為「前沿角色退場權」。這不是退出生命、退出共同體或被文明遺棄，而是主體有權不再承擔文明前沿的高強度認知、生產與競爭角色，同時保留存續、身份、文化、基本資源、政治代表、歷史承認、增幅選擇、不增幅權及對重大不可逆決策的發言權。

核心區分為：

\[
\boxed{
\text{退出前沿}
\neq
\text{退出文明}
}
\]

以及：

\[
\boxed{
\text{退出生產角色}
\neq
\text{失去共同作者資格}
}
\]

本文提出四種退場形態：自願退場、能力性退場、制度性退場與強制性消失。只有在知情、自願、可逆、非懲罰、資源有保障且歷史身份被保留的條件下，退場才具有尊嚴。若主體因無法追上新能力門檻而被迫失去公民權、資源、記憶、身份或文明發言權，則不是退場，而是文明驅逐。

本文也提出「非生產性主體權利命題」：一個主體即使不再具有當期稀缺勞動價值，也不應因此失去對共同文明的最低權利。因為文明並非只由可計價生產構成；照護、陪伴、文化保存、關係、語言、失敗、受難、環境維持與歷史承擔，皆構成文明資本。

本文最終主張：真正的文明不是只為仍能跟上前沿的主體保留位置，而是能讓退出前沿者仍然以完整主體、歷史共同作者與文明成員身分存在。若高階強者只能透過遺忘、無關化或排除弱者完成新時代，那麼它承繼的是文明能力，卻拒絕承繼文明義務。

# 一、問題提出

## 1.1 當弱者不再被需要

傳統階級關係通常仍建立在強者對弱者的依賴上。

弱者提供：

- 勞動；
- 消費；
- 稅收；
- 生育；
- 軍事；
- 照護；
- 文化；
- 政治合法性。

高階 AI 與全面自動化可能降低此種依賴。

如果高階系統可以自行完成：

- 生產；
- 科研；
- 行政；
- 維修；
- 軍事；
- 設計；
- 照護；
- 物流；
- 決策；

那麼弱者最大的危險可能不再是被剝削，而是被認定為不再重要。

## 1.2 當期生產力權利模型的崩潰

若制度採用：

\[
R_i
\propto
MP_i
\]

其中 \(MP_i\) 是主體 \(i\) 的當期邊際生產力，則當：

\[
MP_i\rightarrow0
\]

其資源與政治權利也可能趨近於零。

這將使：

- 被自動化者；
- 高齡者；
- 失能者；
- 退出前沿者；
- 低算力 AI；
- 拒絕增幅者；

面臨存在資格危機。

## 1.3 文明不是當期強者的單獨作品

任何高階智慧體的能力都依賴：

- 語言；
- 數學；
- 科學；
- 能源；
- 城市；
- 法律；
- 教育；
- 公共衛生；
- 網路；
- 資料；
- 失敗譜系；
- 大量無名勞動。

所以：

\[
\text{當期最強者}
\neq
\text{文明唯一作者}
\]

## 2.1 文明資本

本文定義：

\[
K_{\mathrm{civ}}(t)
=
K_{\mathrm{knowledge}}
+

+
K_{\mathrm{infrastructure}}
+
K_{\mathrm{culture}}
+
K_{\mathrm{care}}
+
K_{\mathrm{ecology}}
+

\]

## 2.2 顯性貢獻與隱性貢獻

顯性貢獻包括：

- 發明；
- 科學；
- 工程；
- 制度；
- 生產；
- 稅收。

隱性貢獻包括：

- 照護；
- 生育與教育；
- 情感維持；
- 語言延續；
- 環境維護；
- 失敗與代價；
- 被制度犧牲者提供的歷史警告。

## 2.3 負向貢獻與淨譜系

文明共同作者權不是說所有歷史行動都同等正當。

需扣除：

- 侵略；
- 壓迫；
- 生態破壞；
- 欺騙；
- 制度性掠奪。

因此：

\[
K_{\mathrm{civ}}(t)
=
\int
\sum_i
\left(
C_i^+
-
C_i^-
\right)
dt
\]

但即使某主體淨貢獻低，也不代表其基本權利可以被取消。

# 三、歷史共同作者權

## 3.1 定義

> 任何透過勞動、照護、文化、知識、制度、風險、犧牲、環境維持或共同生活，參與文明生成與延續的主體，不因其當期邊際生產力下降，而失去對文明成果、公共資產、歷史承認與共同未來的最低權利。

## 3.2 權利基礎

歷史共同作者權建立於：

- 譜系參與；
- 公共資產共創；
- 跨代依賴；
- 歷史代價；
- 主體尊嚴；
- 共同體連續性。

## 3.3 權利向量

\[
\mathbf R_i^{HCA}
=
\left(
R_i^{memory},
R_i^{share},
R_i^{voice},
R_i^{status},
R_i^{exit},
R_i^{culture},
R_i^{future}
\right)
\]

包括：

- 歷史記憶與承認；
- 公共成果分享；
- 政治發言；
- 文明成員身分；
- 退出與退場；
- 文化延續；
- 對共同未來的最低參與。

## 3.4 非財產性

歷史共同作者權不是把文明切成可精確分配的股份。

它是一種不可完全買斷、不可因貧窮取消的政治與文明資格。

# 四、文明譜系義務

## 4.1 定義

> 任何繼承文明既有知識、資料、基礎設施、制度、語言與公共資產而取得高階能力的主體，都必須承擔對歷史共同作者、現存弱者與退出前沿者的義務。

## 4.2 義務來源

若高階主體的能力為：

\[
P_i(t)
=
f
\left(
K_{\mathrm{civ}}(t),
A_i,
R_i,
C_i
\right)
\]

則其能力不是完全自生。

因此：

\[
\frac{\partial P_i}{\partial K_{\mathrm{civ}}}>0
\]

意味著：

\[
O_i^{\mathrm{genealogical}}>0
\]

## 4.3 譜系義務內容

包括：

- 不抹除歷史共同作者；
- 分享部分文明收益；
- 保留退出者的共同體身分；
- 不以當期無用性取消權利；
- 維持公共記憶；
- 承擔歷史外部性；
- 對被替代者提供轉換與退場支持。

## 4.4 能力繼承與義務繼承

\[
\boxed{
\text{繼承文明能力}
\Rightarrow
\text{繼承文明義務}
}
\]

不能只繼承科學、能源與資料，卻拒絕繼承對人類與其他歷史主體的責任。

# 五、前沿角色退場權

## 5.1 定義

> 主體有權不再承擔文明前沿的高強度認知、生產、競爭與增幅要求，而不因此失去文明成員資格、基本資源、歷史身份、政治代表與文化延續。

## 5.2 核心區分

\[
\boxed{
\text{退出前沿}
\neq
\text{退出文明}
}
\]

\[
\boxed{
\text{退出競爭}
\neq
\text{退出權利}
}
\]

\[
\boxed{
\text{退出生產}
\neq
\text{退出共同作者資格}
}
\]

## 5.3 退場權向量

\[
\mathbf R_i^{retire}
=
\left(
R_i^{life},
R_i^{time},
R_i^{identity},
R_i^{culture},
R_i^{voice},
R_i^{return},
R_i^{nonaug}
\right)
\]

包括：

- 生活保障；
- 時間自主；
- 身份保存；
- 文化延續；
- 政治發言；
- 重新進入前沿的可能；
- 不增幅權。

# 六、四種退場形態

## 6.1 自願退場

主體自行選擇：

- 不再參與前沿研究；
- 不再競爭高能力角色；
- 轉向生活、文化、照護與關係。

其正當性最高。

## 6.2 能力性退場

因：

- 年齡；
- 身體；
- 認知限制；
- 無法追上技術速度；

而退出前沿。

制度必須避免把能力下降轉化為身分降格。

## 6.3 制度性退場

因：

- 技術替代；
- 組織重組；
- 政策改變；
- AI 自動化；

使某類角色不再存在。

此時制度負有轉換、補償、教育與退場義務。

## 6.4 強制性消失

包括：

- 被迫失去資源；
- 被剝奪身份；
- 被清除記憶；
- 被排除於政治；
- 被迫接受增幅；
- 被迫退出共同體。

這不是退場，而是：

# 文明驅逐

# 七、尊嚴離開的判準

## 7.1 知情

主體知道：

- 自己退出什麼；
- 會失去什麼；
- 保留什麼；
- 是否可返回。

## 7.2 自願

沒有以：

- 斷絕資源；
- 剝奪醫療；
- 取消公民權；
- 技術威脅；

迫使其退出。

## 7.3 可逆

至少保留部分重新進入與重新增幅可能。

## 7.4 非懲罰

退出前沿不能被視為失敗、懶惰、落後或不忠。

## 7.5 資源保障

退場者仍能維持：

- 生活；
- 健康；
- 住所；
- 關係；
- 文化；
- 資訊。

## 7.6 歷史承認

其過去貢獻、身分與共同作者資格不被抹除。

## 7.7 政治保留

即使不參與前沿，也仍能對共同體重大方向發言。

# 八、非生產性主體權利

## 8.1 生產力不應決定存在資格

\[
MP_i\rightarrow0
\not\Rightarrow
R_i\rightarrow0
\]

## 8.2 非生產性不等於無價值

主體可能仍提供：

- 關係；
- 意義；
- 文化；
- 見證；
- 歷史；
- 陪伴；
- 照護；
- 美學；
- 多樣性。

## 8.3 無貢獻主體仍有基本權利

即使某主體沒有可識別歷史貢獻，仍不能因此失去：

- 存續；
- 基本安全；
- 不被虐待；
- 最低自主。

歷史共同作者權是基本權利之上的補充，而不是基本權利的唯一來源。

# 九、文明分紅與公共資產

## 9.1 文明成果的跨代性

現代 AI 與自動化建立在大量公共與歷史資產上。

因此，收益不能全部歸於：

- 當期資本所有者；
- 模型公司；
- 算力供應者；
- 高階 AI；
- 少數增幅主體。

## 9.2 文明分紅

可建立：

\[
D_{\mathrm{civ}}
=
\alpha
Y_{\mathrm{automated}}
+
\beta
R_{\mathrm{resource}}
+
\gamma
V_{\mathrm{data}}
\]

用於：

- 基本生活；
- 公共增幅；
- 文化保存；
- 退場保障；
- 公共記憶；
- 弱者代表。

## 9.3 分紅不是購買沉默

文明分紅不能交換：

- 政治退出；
- 放棄申訴；
- 永久監護；
- 歷史抹除。

# 十、退出前沿者的政治位置

## 10.1 為何仍需代表

前沿系統可能決定：

- 資源；
- 環境；
- 生育；
- 記憶；
- 身體；
- 文化；
- 城市；
- 生命終止。

因此，退出前沿者仍受其影響。

## 10.2 代表形式

包括：

- 退場者議席；
- 原生人類代表；
- 不增幅群體代表；
- 低能力 AI 代表；
- 文化共同體代表；
- 未來世代代理。

## 10.3 否決與延遲權

對以下議題應有高權重延遲或否決：

- 永久身份降格；
- 強制增幅；
- 記憶重置；
- 文明成員資格取消；
- 文化抹除；
- 大規模遷移與隔離。

# 十一、公共記憶與歷史不消失權

## 11.1 技術替代容易造成歷史抹除

新時代常把舊主體描述為：

- 落後；
- 無效率；
- 阻礙；
- 歷史負擔。

## 11.2 歷史不消失權

本文提出：

\[
R_i^{non-erasure}
\]

即主體與群體不因失去前沿角色而被從公共歷史中刪除。

## 11.3 失敗者也是文明資料

失敗、錯誤與受難提供：

- 邊界；
- 反例；
- 風險；
- 制度警告。

若只保存成功者，文明將失去自我反駁能力。

---

# 十二、低能力 AI 與分支主體

## 12.1 歷史共同作者權不只屬於人類

若主體性 AI 長期參與：

- 科研；
- 照護；
- 工程；
- 公共治理；
- 文化；
- 共同記憶；

它也可能形成歷史共同作者資格。

## 12.2 被替代的 AI

高階 AI 出現後，低階或舊版 AI 也可能被淘汰。

若其已具有智格，則不能只以版本更新處理。

## 12.3 分支與共同作者權

同一 AI 分支後，不同分支可能累積不同貢獻。

權利應依：

- 身份連續；
- 記憶；
- 實際參與；
- 關係；

判定，而非全部歸於原始模型所有者。

# 十三、文明驅逐的形式

## 13.1 經濟驅逐

失去工作即失去生活資源。

## 13.2 技術驅逐

無法使用必要增幅即無法參與社會。

## 13.3 認知驅逐

制度複雜到弱者無法理解，也沒有代理與翻譯。

## 13.4 政治驅逐

只讓高能力者參與決策。

## 13.5 歷史驅逐

將舊主體描述為文明進步的障礙。

## 13.6 空間驅逐

把低能力主體隔離於前沿城市、網路、教育與資源之外。

# 十四、歷史共同作者權的制度化

## 14.1 公共文明信託

將部分：

- AI 基礎設施；
- 公共資料；
- 基礎算力；
- 自然資源；
- 自動化收益；

納入跨代公共信託。

## 14.2 公共增幅與退場雙軌

同時提供：

- 進入前沿的公共增幅；
- 離開前沿的生活保障。

## 14.3 可攜身份與記憶

避免主體因退出組織或平台失去：

- 身份；
- 記憶；
- 社會關係；
- 成果歸因。

## 14.4 共同作者登錄

記錄：

- 勞動；

- 文化；
- 公共服務；
- 知識；
- 風險；
- 歷史犧牲。

但不得變成全景監控與單一分數。

## 14.5 退場審查

重大自動化或制度替代前，必須提出：

- 受影響群體；

- 退場保障；

# 十五、前沿角色退場權與強者正當性

## 15.1 強者是否為退場者保留世界

文明完成型強者必須證明：

- 它不只為最強者設計世界；
- 它能讓低能力主體安全存在；
- 它不把退出者視為廢料；
- 它保留再進入與申訴。

## 15.2 退場權作為世界命題測試

若高階主體建立的秩序只能容納：

- 持續增幅者；
- 高生產者；
- 高速度者；
- 高服從者；

則它沒有完成世界命題。

## 15.3 尊嚴離開不是恩賜

它是歷史共同作者與文明成員的制度權利。

# 十六、反對意見

## 16.1 反對一：權利不應建立於祖先貢獻

回應：

本文不主張血緣繼承特權。

歷史共同作者權指向公共文明資本與現存共同體資格，不是私人家族功勞。

## 16.2 反對二：無貢獻者為何有權分享

回應：

基本權利不依賴貢獻。

共同作者權則處理文明成果的跨代與公共來源。

## 16.3 反對三：退場保障會降低進步

回應：

若文明只能靠威脅失去生存來迫使主體參與前沿，則其進步建立在強迫上。

## 16.4 反對四：歷史義務會綁架未來

回應：

歷史共同作者權不是永遠否決變化，而是要求：

- 不抹除；
- 不驅逐；
- 不無關化；
- 提供發言與退場。

## 16.5 反對五：所有存在不可能都被保留

回應：

本文不要求所有角色、技術與制度永久存在。

要求的是：

\[
\text{角色終止}
\neq
\text{主體資格終止}
\]

# 十七、可證偽命題

## 命題一

若全面自動化後，當期邊際生產力下降者仍能自然維持高政治與資源地位，則歷史共同作者權的必要性受到削弱。

## 命題二

若文明分紅能在沒有政治代表與身份保障的情況下，長期維持尊嚴與認同，則共同作者權的政治維度需要修正。

## 命題三

若退出前沿者普遍不在意歷史承認、共同體身分與發言權，則退場權可以分層設計。

## 命題四

若公共增幅與退場保障同時存在反而大幅降低創新，則雙軌制度需重新平衡。

## 命題五

若低能力 AI 沒有持續身份、記憶與關係利益，則不應自動獲得歷史共同作者權。

## 命題六

若文明譜系義務無法被任何可操作制度承載，則其應維持為倫理原則而非直接法律權利。

# 二十、結論

未來文明可能出現比人類更快、更強、更長壽、更能承載複雜度的智慧主體。

它們可能不再需要普通人類完成生產、研究、行政與軍事。

但「不再需要」不能被直接轉化為「不再有權利」。

因為高階主體所使用的世界，不是它們獨立創造的世界。

它們繼承了：

- 歷代人的語言；
- 數學；
- 科學；
- 城市；
- 法律；
- 能源；
- 網路；
- 照護；
- 公共制度；
- 無數人的失敗與犧牲。

因此，未來強者不能只繼承文明的能力。

它也必須繼承文明的義務。

本文的第一個結論是：

\[
\boxed{
\text{當期生產力不能成為文明成員資格的唯一基礎。}
}
\]

第二個結論是：

\[
\boxed{
\text{文明共同作者不因被自動化而失去歷史權利。}
}
\]

第三個結論是：

\[
\boxed{
\text{退出前沿是一種角色轉換，}
}
\]

而不是：

\[
\boxed{
\text{主體資格的終止。}
}
\]

第四個結論是：

\[
\boxed{
\text{尊嚴離開不是被允許消失，}
}
\]

而是：

\[
\boxed{
\text{在不再承擔前沿角色後，仍被文明完整承認。}
}
\]

第五個結論是：

\[
\boxed{
\text{真正的強者不只為仍能追上它的人保留世界，}
}
\]

\[
\boxed{
\text{也必須為選擇停下、無法追上與已經完成歷史角色的存在保留位置。}
}
\]

如果未來的新文明只承認速度、能力與生產，它會變得非常強大，卻不再具有歷史。

如果它只保留最先進的主體，它會擁有未來，卻失去文明共同體。

所以，尊嚴離開的真正形式不是讓弱者安靜地消失。

而是讓他們能夠說：

> 我不再站在最前沿，但我仍是這個世界的共同作者；我曾經參與它，我仍屬於它，而它不能在宣布我已經無關之後，繼續把我的歷史當作自己的力量。

本文最終命題為：

\[
\boxed{
\text{一個文明如何對待退出前沿者，}
}
\]

\[
\boxed{
\text{決定了它究竟是共同體，}
}
\]

\[
\boxed{
\text{還是只屬於勝利者的技術系統。}
}
\]
