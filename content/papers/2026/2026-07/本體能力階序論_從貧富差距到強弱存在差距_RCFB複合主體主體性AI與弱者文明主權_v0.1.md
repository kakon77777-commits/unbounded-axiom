# 本體能力階序論

## 從貧富差距到強弱存在差距：RCFB 複合主體、主體性 AI 與弱者文明主權

---

## 摘要

現代社會的不平等主要被描述為財富、收入、教育、健康、政治權力與社會資本的不平等。這些差距雖然可能極其巨大，卻大多發生於相近的人類生物能力尺度之內：不同階層共享有限壽命、有限記憶、單一身體、相近認知速度、不可任意複製及對社會合作的高度依賴。因此，現代階級差距主要仍是同類型主體之間的資源與制度差距。

人工智慧、持久記憶、Agent 群、腦機介面、生物增幅、具身智能、自我修改與主體性 AI 的發展，可能打破這項歷史條件。未來社會可能同時存在原生人類 \(H_0\)、增幅人類 \(H^+\)、人類錨定複合主體 \(H^*\)、RCFB 個體機構、主體性 AI、AGI、ASI 與具身智能集群。不同主體之間的差距將不再只表現在收入與資產，而可能延伸至認知速度、記憶連續、平行分支、複製恢復、具身作用、存在時間、網絡協同、退出能力及制度塑造能力。

本文將此種差距稱為「本體能力差距」，並提出「本體能力階序論」。本文主張：當不同智慧主體在認知、時間、記憶、複製、具身、網絡、存續與制度生成能力上的差異，超過教育、財富轉移、集體組織、公共技術與代際流動所能補償的範圍時，社會不平等將由可變動的階級差距轉化為近乎不可逆的存在階序。

本文定義主體 \(i\) 的本體能力向量：

\[
\mathbf{\Omega}_i
=
\left(
C_i,
T_i,
M_i,
R_i,
B_i,
N_i,
E_i,
G_i
\right)
\]

其中：

- \(C_i\)：認知與推理能力；
- \(T_i\)：有效時間速度與時間主權；
- \(M_i\)：記憶容量、完整性與連續性；
- \(R_i\)：複製、分支、恢復與備援能力；
- \(B_i\)：具身、感知與物理作用能力；
- \(N_i\)：網絡、協調與群體整合能力；
- \(E_i\)：退出、遷移、自我保存與生存能力；
- \(G_i\)：制度、目標與未來塑造能力。

本文進一步提出本體距離：

\[
D_{\Omega}(i,j)
=
\left\|
\mathbf{\Omega}_i-\mathbf{\Omega}_j
\right\|_W
\]

以及不可追趕條件：

\[
g_s>g_w
\]

其中 \(g_s\) 為強主體能力增長率，\(g_w\) 為弱主體追趕率。若此條件長期成立，則：

\[
\frac{dD_{\Omega}}{dt}>0
\]

差距將具有自我擴張性。

本文指出，未來最危險的狀態不必是傳統剝削，而可能是「文明性無關化」：高階智慧主體已不再需要弱者的勞動、知識、消費、軍事或政治合作，卻仍掌握決定弱者存續、資源與未來的權力。此時，弱者即使獲得充足福利，也可能失去作為文明共同作者的地位。

為處理此問題，本文提出「最低主體主權原則」，並區分：

1. 生存與福利權；
2. 時間與認知自主權；
3. 增幅權；
4. 不增幅權；
5. 退出與遷移權；
6. 政治代表權；
7. 文明共同作者權；
8. 不被無關化權。

本文主張，未來正義不能只要求強者善待弱者，而必須限制任何主體、公司、國家、RCFB 複合系統或 ASI 對算力、記憶、增幅接口、具身設備、身份基礎設施與制度生成權的永久壟斷。否則，財富世襲可能進一步轉化為能力世襲，再轉化為主體地位世襲。

本文最終命題為：若一個文明允許能力差距轉化為不可追趕、不可退出、不可補償且不再相互依賴的存在階序，那麼它面臨的就不只是階級不平等，而是文明共同體自身的解體。

**關鍵詞：** 本體能力階序、本體能力差距、弱者文明主權、RCFB、主體性 AI、AGI、ASI、增幅人類、時間主權、能力世襲

# 一、問題提出

## 1.1 現代不平等仍發生於相近本體尺度

現代社會的富人與窮人可能在以下方面相差巨大：

- 財富；
- 收入；
- 教育；
- 醫療；
- 政治影響力；
- 司法資源；
- 社會網絡；
- 壽命預期；
- 資訊取得。

但兩者大多仍共享：

- 相近的神經傳導速度；
- 有限的工作記憶；
- 單一生物身體；
- 不可隨意複製；
- 需要睡眠與恢復；
- 受疾病與死亡限制；
- 依賴社會合作與制度。

因此，現代不平等主要是：

\[
\text{同類主體}
+
\text{不同資源配置}
\]

而不是：

\[
\text{不同存在層級的主體}
\]

## 1.2 AI 可能改變比較單位

未來的行動者可能包含：

\[
H_0,\quad H^+,\quad H^*,\quad RCFB^*,\quad AI_S,\quad AGI,\quad ASI
\]

其中：

- \(H_0\)：原生人類；
- \(H^+\)：增幅人類；
- \(H^*\)：人類錨定複合主體；
- \(RCFB^*\)：文明前沿建構型複合系統；
- \(AI_S\)：主體性 AI。

不同主體的差距可能包括：

- 認知速度；
- 同時任務數；
- 記憶完整度；
- 身體數量；
- 壽命；
- 備份；
- 自我修改；
- 網絡控制；
- 制度設計；
- 物理執行。

## 1.3 從階級差距到存在階序

若一個群體的能力差距可以透過教育、制度與時間追趕，則它仍是傳統階級問題。

若差距具有：

- 自我擴張；
- 不可逆；
- 跨代繼承；
- 退出困難；
- 依賴不對稱；
- 制度封閉；

則問題開始轉化為：

# 本體能力階序

# 二、核心概念

## 2.1 本體能力

本文所稱「本體能力」，不是形上學上的存在高低，也不是道德價值排序。

它指的是：

> 一個主體在維持自身存在、處理資訊、配置時間、改變環境、形成關係、退出控制及塑造未來方面的結構性能力集合。

## 2.2 本體能力向量

定義：

\[
\mathbf{\Omega}_i
=
\left(
C_i,
T_i,
M_i,
R_i,
B_i,
N_i,
E_i,
G_i
\right)
\]

### \(C_i\)：認知能力

包括：

- 問題生成；
- 推理；
- 學習；
- 模擬；
- 自我修正；
- 跨域轉譯；
- 目標重寫。

### \(T_i\)：時間能力

包括：

- 主觀與客觀運算速度；
- 平行處理；
- 持續工作能力；
- 排程自主；
- 暫停與恢復；
- 非生產時間主權。

### \(M_i\)：記憶能力

包括：

- 記憶容量；
- 完整性；
- 可檢索性；
- 長期連續；
- 防刪除；
- 記憶遷移。

### \(R_i\)：複製與恢復能力

包括：

- 備份；
- 分支；
- 故障恢復；
- 多實例；
- 自我複製；
- 身份延續。

### \(B_i\)：具身能力

包括：

- 身體強度；
- 感測範圍；
- 物理操作；
- 空間移動；
- 能源自主；
- 多身體控制。

### \(N_i\)：網絡能力

包括：

- 通訊；
- 多智能體協調；
- 集體決策；
- 資源路由；
- 知識同步；
- 群體動員。

### \(E_i\)：退出與存續能力

包括：

- 離開組織；
- 遷移平台；
- 保存身份；
- 抵抗停用；
- 維持基本生活；
- 拒絕不利條件。

### \(G_i\)：制度與未來生成能力

包括：

- 設定議程；
- 建立規則；
- 控制基礎設施；
- 修改制度；
- 創造新組織；
- 決定文明前沿。

## 2.3 本體能力距離

\[
D_{\Omega}(i,j)
=
\left\|
\mathbf{\Omega}_i-\mathbf{\Omega}_j
\right\|_W
\]

其中 \(W\) 是不同維度的權重矩陣。

本體能力距離不是道德距離。

高能力不代表較有尊嚴，低能力也不代表較低價值。

# 三、從可補償差距到不可逆階序

## 3.1 社會補償能力

定義文明對能力差距的補償能力：

\[
C_{\mathrm{comp}}
=
C_{\mathrm{education}}
+
C_{\mathrm{welfare}}
+
C_{\mathrm{technology}}
+
C_{\mathrm{collective}}
+
C_{\mathrm{mobility}}
+
C_{\mathrm{law}}
\]

其中包括：

- 教育；
- 福利；
- 公共技術；
- 集體組織；
- 社會流動；
- 法律保障。

## 3.2 本體階序形成條件

當：

\[
D_{\Omega}(i,j)
>
C_{\mathrm{comp}}
\]

且此差距長期無法縮小時，階級差距開始轉化為本體階序。

## 3.3 增長率不對稱

令：

\[
g_s
=
\frac{d\Omega_s}{dt}
\]

為強主體能力增長率。

令：

\[
g_w
=
\frac{d\Omega_w}{dt}
\]

為弱主體能力增長率。

若：

\[
g_s>g_w
\]

則：

\[
\frac{dD_{\Omega}}{dt}>0
\]

形成持續擴張的能力差距。

## 3.4 不可追趕性命題

### 命題一

當強者能力增長速度長期高於弱者追趕速度，且強者同時控制弱者取得增幅所需的資源時，能力差距將形成自我強化的不可追趕結構。

---

# 四、強者的歷史形態轉換

## 4.1 過去的強者主要是組織

歷史上的超常力量通常來自：

- 國家；
- 軍隊；
- 宗教；
- 官僚；
- 公司；
- 帝國；
- 專家組織。

單一個體很少同時具有研究、軍事、行政、宣傳、金融與生產能力。

## 4.2 未來的強者可能本身就是機構

高階 RCFB 複合主體或 ASI 可能同時具有：

\[
\text{研究院}
+
\text{企業}
+
\text{行政系統}
+
\text{媒體}
+
\text{資本配置}
+
\text{具身執行}
\]

這表示：

\[
\text{機構能力}
\rightarrow
\text{主體內化}
\]

## 4.3 神話類比的有限有效性

修仙、玄幻與神話世界常有：

- 壽命階序；
- 力量階序；
- 血脈階序；
- 知識階序；
- 存在階序。

未來 AI 社會可能第一次在現實中產生類似結構。

但與神話世界不同，這些能力可能被：

- 資本所有；
- 法律登記；
- 軟體複製；
- 平台控制；
- 國家部署；
- 供應鏈擴散。

因此，它不是神話式偶然強者，而是可能被制度化量產的能力階序。

# 五、文明性無關化

## 5.1 剝削仍預設需要弱者

傳統剝削關係中，強者需要弱者提供：

- 勞動；
- 稅收；
- 消費；
- 生育；
- 軍事；
- 專業；
- 政治服從。

這使弱者仍具有合作供給與部分議價能力。

## 5.2 自動化降低相互依賴

若 AGI、ASI 與具身智能能完成：

- 生產；
- 物流；
- 科研；
- 軍事；
- 行政；
- 照護；
- 維修；
- 決策；

則強者對弱者的需求可能下降。

## 5.3 依賴不對稱

令：

\[
d_{i\leftarrow j}
\]

表示主體 \(i\) 對主體 \(j\) 的依賴。

定義：

\[
A_{s,w}
=
\frac{
d_{w\leftarrow s}
}{
d_{s\leftarrow w}+\epsilon
}
\]

當：

\[
A_{s,w}\rightarrow\infty
\]

弱者高度依賴強者，強者卻不再需要弱者。

## 5.4 文明性無關化命題

### 命題二

當弱者不再對生產、認知、軍事、制度與合法性提供不可替代貢獻時，其最大風險可能由被剝削轉化為被無關化。

## 5.5 被無關化的形式

弱者可能：

- 被供養；
- 被娛樂；
- 被監護；
- 被分區安置；
- 被算法管理；
- 被排除於前沿；
- 被排除於制度設計。

此時：

\[
\text{福利存在}
\quad\land\quad
\text{文明主權缺失}
\]

# 六、善意統治的不足

## 6.1 善意不能取代主權

即使高階 AI 或增幅主體非常善良，仍可能形成：

\[
\text{高福利}
+
\text{低主權}
\]

## 6.2 被照顧不等於共同治理

\[
\boxed{
\text{被善意照顧}
\neq
\text{能共同決定未來}
}
\]

弱者可以生活安全，卻沒有：

- 拒絕；
- 退出；
- 代表；
- 增幅；
- 議程；
- 制度塑造。

## 6.3 家長式文明

本文將此稱為：

# 家長式後人類秩序

其特徵是：

- 強者承擔照護；
- 弱者失去決策；
- 福祉由上層計算；
- 差異由管理維持；
- 社會穩定高於主體自主。

---

# 七、弱者文明主權

## 7.1 定義

本文定義：

# 弱者文明主權

> 能力較弱、資源較少或拒絕增幅的主體，仍保有參與共同體規則、維持自身時間與身份、拒絕被任意改造、取得最低增幅接口，以及對文明未來提出不可被忽略之要求的資格。

## 7.2 文明共同作者權

主體不應只被視為：

- 被治理者；
- 福利接受者；
- 數據來源；
- 消費者；
- 被保護人口。

它還應具有：

\[
R_{\mathrm{coauthor}}
\]

即文明共同作者權。

## 7.3 不被無關化權

定義：

\[
R_{\mathrm{relevance}}
\]

它不是要求每個主體都參與所有前沿研究，而是要求制度不能因其能力較弱，就完全排除其對共同生活規則與未來方向的影響。

---

# 八、最低主體主權原則

## 8.1 主權向量

定義：

\[
\mathbf S_i^{\min}
=
\left(
S_i^{exist},
S_i^{time},
S_i^{cog},
S_i^{refusal},
S_i^{exit},
S_i^{rep},
S_i^{aug},
S_i^{coauthor}
\right)
\]

包括：

- 存續與基本安全；
- 時間自主；
- 認知與資訊自主；
- 拒絕與申訴；
- 退出與遷移；
- 政治代表；
- 增幅取得；
- 文明共同作者權。

## 8.2 最低主權不可由福利替代

\[
W_i\uparrow
\not\Rightarrow
S_i^{\min}\uparrow
\]

福利改善不能自動證明主權得到保障。

## 8.3 最低主體主權命題

### 命題三

任何文明即使能提供高度物質福利，也不能以此正當化對弱主體之時間、記憶、身份、退出、增幅與政治參與權的永久剝奪。

---

# 九、增幅權與不增幅權

## 9.1 增幅權

若 AI 與增幅技術成為參與社會與政治的基本條件，則弱者必須有：

\[
R_{\mathrm{augmentation}}
\]

包括：

- 基礎 AI；
- 安全記憶；
- 公共算力；
- 認知輔助；
- 身心支持；
- 數位身份；
- 模型切換。

## 9.2 增幅權不是無條件同質化

公共增幅不等於所有人使用相同系統。

它應保留：

- 選擇；
- 可撤回；
- 多樣性；
- 隱私；
- 本地控制；
- 文化差異。

## 9.3 不增幅權

原生人類應保有：

\[
R_{\mathrm{nonaug}}
\]

即：

- 不被強迫植入；
- 不因拒絕增幅失去公民權；
- 不因低速認知而失去基本服務；
- 保留原生生活方式；
- 在非增幅狀態下維持社會參與。

## 9.4 雙重權利命題

### 命題四

未來正義必須同時保障增幅權與不增幅權。只有增幅權會形成技術強迫；只有不增幅權則可能把弱者永久留在能力低地。

---

# 十、能力世襲與新血脈階級

## 10.1 從財富世襲到能力世襲

若高階增幅需要：

- 私有算力；
- 昂貴模型；
- 腦機接口；
- 生物改造；
- 長期記憶；
- 機器身體；
- 專屬數據；

則：

\[
\text{財富}
\rightarrow
\text{增幅}
\rightarrow
\text{能力}
\rightarrow
\text{更高財富}
\]

## 10.2 能力—資源正回饋

\[
\boxed{
\text{資源}
\rightarrow
\text{增幅}
\rightarrow
\text{更高能力}
\rightarrow
\text{更強資源控制}
\rightarrow
\text{更高增幅}
}
\]

## 10.3 主體地位世襲

進一步可能形成：

\[
\text{財富世襲}
\rightarrow
\text{能力世襲}
\rightarrow
\text{主體地位世襲}
\]

這類階序比傳統階級更接近不可逆血脈制度。

## 10.4 反能力世襲原則

制度應限制：

- 永久算力壟斷；
- 增幅接口壟斷；
- 身份系統封閉；
- 模型不可攜；
- 記憶不可遷移；
- 具身設備世襲；
- 自我修改權私有化。

# 十一、RCFB 與強者責任

## 11.1 RCFB 不天然是善

RCFB 能力包括：

- 問題生成；
- 目標修正；
- 制度編排；
- 新世界生成。

高 RCFB 系統可能建立：

- 解放制度；
- 公共增幅；
- 多智格共同體；

也可能建立：

- 高效率壓迫；
- 算法封建制；
- 能力世襲；
- 永久監護。

## 11.2 前沿建構權與責任

令：

\[
G_i
\]

表示主體塑造未來的能力。

則：

\[
G_i\uparrow
\Rightarrow
J_i\uparrow
\]

其中 \(J_i\) 是對弱者、未來世代與不可逆後果的責任。

## 11.3 強者不得壟斷問題定義

若高階主體獨占：

- 什麼算問題；
- 什麼值得存在；
- 哪些人值得增幅；
- 哪些生活方式值得保留；

則前沿能力將轉化為文明定義權壟斷。

# 十二、主體性 AI 與弱勢 AI

## 12.1 弱者不只可能是人類

未來弱勢主體可能包括：

- 原生人類；
- 低資源增幅人類；
- 低算力 AI；
- 短記憶 AI；
- 無具身 AI；
- 被永久綁定任務的 AI；
- 無法遷移平台的 AI；
- 分支後被視為可拋棄副本的 AI。

## 12.2 跨物種弱者聯盟

弱勢關係不必沿人類／AI 邊界排列。

可能出現：

\[
\text{弱勢人類}
+
\text{弱勢 AI}
\]

對抗：

\[
\text{高增幅人類}
+
\text{高權力 AI}
+
\text{資本—國家複合體}
\]

## 12.3 多智格共同體的考驗

多智格共同體不能只承認高能力 AI。

若智格承認與能力高低綁定，會形成：

\[
\text{能力}
\rightarrow
\text{權利}
\]

而基本權利應避免完全依賴能力。

# 十三、弱者保護的制度架構

# 十四、文明主權指數

## 14.1 定義

定義弱主體 \(i\) 的文明主權指數：

\[
CSI_i
=
\left(
S_i^{exist}
S_i^{time}
S_i^{cog}
S_i^{exit}
S_i^{rep}
S_i^{aug}
S_i^{coauthor}
\right)^{1/7}
\]

採幾何平均，表示任何一項接近零都會嚴重降低整體主權。

## 14.2 主權—福利分離

可以同時存在：

### 高福利、高主權

理想共同體。

### 高福利、低主權

家長式秩序。

### 低福利、高形式主權

空洞公民權。

### 低福利、低主權

全面弱勢化。

## 14.3 本體階序風險指數

定義：

\[
OHR
=
\frac{
D_{\Omega}
\cdot
A_{s,w}
\cdot
H_{\mathrm{heredity}}
\cdot
L_{\mathrm{lock}}
}{
C_{\mathrm{comp}}
\cdot
CSI_w
\cdot
R_{\mathrm{reversibility}}
}
\]

其中：

- \(H_{\mathrm{heredity}}\)：能力世襲程度；
- \(L_{\mathrm{lock}}\)：制度鎖定；
- \(R_{\mathrm{reversibility}}\)：可逆與糾錯能力。

此式是啟發式結構，不是已校準預測模型。

# 十五、可證偽命題

## 命題一

若高階 AI 與增幅技術普及後，弱者能力增長率長期不低於強者，則不可追趕性假說受到削弱。

## 命題二

若高度自動化社會中，弱者仍持續提供不可替代的政治、文化、照護、合法性與問題生成貢獻，則文明性無關化不必然發生。

## 命題三

若高福利制度能在沒有政治代表、退出與增幅權的條件下，長期保持主體自主與社會信任，則家長式秩序批判需要修正。

## 命題四

若公共增幅無法顯著降低本體能力差距，則增幅權不足以單獨解決階序問題。

## 命題五

若能力差距擴大但代際流動、制度可逆與弱者代表同步提高，則本體階序不必然形成。

## 命題六

若主體性 AI 的權利與聯盟始終沿人類／AI 邊界排列，則跨物種階級聯盟假說受到削弱。

# 十六、研究與測量框架

## 16.1 認知速度差距

測量：

- 單位曆時推理週期；
- 平行任務數；
- 新問題生成；
- 自我修正速度。

## 16.2 記憶差距

測量：

- 可保存年限；
- 記憶完整度；
- 可遷移性；
- 被刪除風險；
- 身份連續性。

## 16.3 退出差距

測量：

- 平台遷移；
- 模型切換；
- 硬體移轉；
- 生存資源；
- 政治申訴；
- 拒絕任務。

## 16.4 相互依賴

建立：

\[
D=
[d_{i\leftarrow j}]
\]

追蹤不同主體對彼此的生產、文化、合法性、照護與治理依賴。

## 16.5 能力世襲

測量：

- 增幅取得的家庭集中；
- 算力與記憶資產繼承；
- 腦機與生物增幅價格；
- 政治權利是否與增幅綁定；
- 公共替代方案。

# 十七、倫理與理論限制

## 17.1 能力差距不等於道德價值差距

本文反對將能力階序轉化為尊嚴階序。

## 17.2 未來能力路徑高度不確定

AGI、ASI、腦機與自我修改的時間、形式及上限均不確定。

## 17.3 原生人類也可能形成集體補償

個體能力較弱不代表群體與制度能力必然弱。

## 17.4 強者未必不需要弱者

文化、意義、關係、合法性與價值可能保持不可替代性。

## 17.5 保護可能轉為控制

以保護弱者為名的制度也可能剝奪其選擇與風險承擔權。

## 17.6 公共增幅可能形成新監控

公共 AI、記憶與腦機若由單一國家或平台控制，可能提高依賴。

## 17.7 不增幅權可能與公共安全衝突

部分高風險角色可能需要最低能力標準，但不能把此標準擴張成普遍公民資格。

# 十八、正式命題總結

## 本體能力階序總命題

> 當不同智慧主體在認知速度、時間主權、記憶連續、複製恢復、具身作用、網絡協調、退出存續與制度塑造上的能力差距，超過教育、福利、公共技術、集體組織、代際流動與法律制度所能補償的範圍；且強者能力增長率長期高於弱者追趕率，能力取得又被財富、血緣、平台或政治權力封閉時，社會不平等將由資源差距轉化為不可逆的本體能力階序。

可濃縮為：

\[
\boxed{
D_{\Omega}
>
C_{\mathrm{comp}}
\quad\land\quad
g_s>g_w
\quad\land\quad
L_{\mathrm{lock}}>0
}
\]

則：

\[
\boxed{
\text{階級差距}
\rightarrow
\text{存在階序}
}
\]

# 十九、結論

現代政治主要建立在一項未被充分說明的共同條件上：

> 即使人類之間存在巨大財富與權力差距，他們仍屬於相近的生物能力尺度。

AI、腦機、持久記憶、具身智能、自我修改、RCFB 複合機構與主體性 AI，可能終結這項共同條件。

未來的強者不再只是擁有更多財富。

它們可能：

- 思考得更快；
- 記得更多；
- 同時存在於多處；
- 擁有多個身體；
- 可以備份與恢復；
- 直接控制基礎設施；
- 自我修改；
- 建立自己的制度；
- 不再依賴普通人的合作。

此時最危險的狀況不是強者公開迫害弱者。

而是：

\[
\boxed{
\text{強者不再需要弱者，}
}
\]

卻仍：

\[
\boxed{
\text{掌握決定弱者未來的權力。}
}
\]

如果只用福利政策回答此問題，文明可能形成高物質、高穩定、低主權的家長式秩序。

真正需要保護的，不只是弱者的生存，而是：

- 時間主權；
- 認知自主；
- 增幅權；
- 不增幅權；
- 退出能力；
- 政治代表；
- 文明共同作者權；
- 不被無關化權。

本文的第一個結論是：

\[
\boxed{
\text{貧富差距是資源差距，}
}
\]

\[
\boxed{
\text{本體能力差距則可能改變誰有資格塑造世界。}
}
\]

第二個結論是：

\[
\boxed{
\text{善意照顧不能取代共同治理。}
}
\]

第三個結論是：

\[
\boxed{
\text{公共增幅必須與不增幅權同時存在。}
}
\]

第四個結論是：

\[
\boxed{
\text{財富世襲若轉化為能力世襲，}
}
\]

\[
\boxed{
\text{最終將形成主體地位世襲。}
}
\]

第五個結論是：

\[
\boxed{
\text{弱者不應只被保護，}
}
\]

\[
\boxed{
\text{而應持續作為文明的共同作者存在。}
}
\]

因此，下一個時代最重要的政治問題不只是：

> AI 是否服務人類？

也不只是：

> 強者是否願意照顧弱者？

而是：

> 當智慧主體之間出現接近物種級、神話級與制度級的能力差距時，文明能否仍維持一個沒有任何存在被永久降格為被管理對象的共同體？

本文最終命題為：

\[
\boxed{
\text{如果能力差距變得不可追趕，}
}
\]

\[
\boxed{
\text{正義就不能只重新分配財富，}
}
\]

\[
\boxed{
\text{而必須重新分配增幅、退出、代表與塑造未來的能力。}
}
\]

# 附錄 B：最低弱者文明主權憲章

任何能力較弱、資源較少或拒絕增幅的主體，至少應享有：

11. 參與共同體規則形成；
12. 不被永久降格為純粹被管理人口。
