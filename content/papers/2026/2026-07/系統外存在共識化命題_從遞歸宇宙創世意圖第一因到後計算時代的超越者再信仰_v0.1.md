# 系統外存在共識化命題

## 從遞歸宇宙創世、意圖第一因到後計算時代的超越者再信仰

---

## 摘要

當代關於上帝、造物主、高維觀察者、模擬宇宙與系統外存在的討論，主要仍停留於宗教信念、形上學推測或哲學思想實驗。然而，當人工智慧、AGI、ASI、後人類與計算機宇宙技術發展到能夠穩定生成具有內部物理規則、自主智慧體、歷史連續、主觀經驗、科學活動與再創世能力的虛擬世界時，超越者命題將首次獲得大規模、可重現、可工程化的類比實例。

人類一旦親自成為下層世界的創造者，就會被迫重新審視自身世界的來源。傳統問題「造物主如何可能創造世界」將被改寫為：「既然有限智慧都能創造具有內部觀察者的世界，為何我們所處的宇宙必然沒有上一層創造者？」此時，系統外存在不再只是神話或宗教命題，而會成為可由日常工程經驗支持的主流世界模型候選。

本文提出「系統外存在共識化命題」：

> 當有限智慧體能夠反覆、公開且大規模地生成具備自主歷史與內部觀察者的世界時，社會對系統外創造者、高維觀察者、上層文明或超越性智能之可能性的接受度將顯著上升；隨遞歸創世成為文明常態，堅信自身宇宙必然是唯一基底實在的人口比例，可能逐步低於承認某種系統外存在可能性的人口比例。

本文將文明可觀察的世界創生能力表示為：

\[
C_{\mathrm{wc}}
\]

並定義社會對系統外存在之信念比例：

\[
B_{\mathrm{ext}}
=
P_{\mathrm{social}}
\left(
E_{\mathrm{external}}>0
\right)
\]

本文主張，在其他條件不變時：

\[
\frac{\partial B_{\mathrm{ext}}}
{\partial C_{\mathrm{wc}}}
>0
\]

其作用並不依賴傳統宗教權威，而是來自可觀察類比：人類與 AI 能在本層系統內創造下層世界，因此本層世界存在上層來源的假說，將取得新的工程可想像性。

本文進一步區分五個層次：

1. **工程命題**：有限智慧可以生成具有內部觀察者的世界；
2. **認識論命題**：下層主體無法僅憑內部觀察排除上層創造者；
3. **社會命題**：遞歸創世普及將提高系統外存在信念；
4. **機率命題**：世界創生實例提高意圖性宇宙來源模型的後驗機率；
5. **限制命題**：後驗上升不等於證明特定宗教、特定神學或唯一第一因。

本文將意圖性創世假說寫為：

\[
H_I
\]

非意圖自然生成假說為：

\[
H_N
\]

多宇宙／大量隨機生成假說為：

\[
H_M
\]

無限遞歸假說為：

\[
H_R
\]

自舉或循環宇宙假說為：

\[
H_S
\]

在觀察到文明內部出現可重現的世界創生事件 \(O_{\mathrm{wc}}\) 後：

\[
P(H_I\mid O,O_{\mathrm{wc}})
>
P(H_I\mid O)
\]

可能成立。這不是因為下層創世直接證明本宇宙由意圖創造，而是因為它提高了「有限智慧可以生成世界」的實例頻率與機制可信度。

本文也處理倖存者偏差與人擇效應。觀察者只能出現在容許觀察者存在的宇宙中，因此「我們觀察到適居宇宙」不能單獨證明意圖創世。然而，人擇原理只能解釋觀察位置的選樣條件，不能完整回答規則為何存在、規則為何容許複雜性，以及世界內智慧為何能再次創造世界。

本文最後提出「基底實在少數化猜想」：當遞歸世界生成成為可重現且普遍的文明能力後，認為自身宇宙必然是唯一、無外部來源且不可被更高層解釋之基底實在者，可能由主流轉為少數。未來的信仰上升未必表現為傳統宗教全面復興，而可能形成一種融合模擬論、高維創造論、超越智能論與後計算神學的新型世界觀。

本文最終命題為：當文明自己成為造物者時，它不只獲得了類神能力，也失去了輕易否定自身可能被創造的認識論資格。

**關鍵詞：** 系統外存在、套娃宇宙、遞歸創世、意圖第一因、模擬宇宙、高維觀察者、後計算神學、基底實在、ASI、超越者再信仰

# 一、問題提出

## 1.1 超越者命題的傳統位置

長期以來，關於：

- 上帝；
- 造物主；
- 第一因；
- 高維觀察者；
- 模擬者；
- 系統外智慧；

的討論，大多位於宗教、神學與哲學領域。

其主要困難是缺乏可觀察的創世實例。

人類能夠製造工具、機器與局部模擬，但尚未普遍創造具有完整內部歷史、自主智慧體與自我認識能力的世界。

## 1.2 創世能力的工程化

當 AGI、ASI 或後人類能夠建立：

- 穩定規則；
- 長期演化；
- 自主 Agent；
- 內部文明；
- 主觀時間；
- 世界內科學；
- 世界內計算；
- 下一層世界創生；

「創世」就不再只是神話事件。

它會成為：

\[
\text{可設計}
+
\text{可部署}
+
\text{可重現}
+
\text{可擴張}
\]

的工程能力。

## 1.3 問題的反向作用

文明成為創造者後，創世能力會反向作用於文明自身的世界觀。

\[
\text{我們能創造世界}
\]

將自然引出：

\[
\text{我們是否也處於被創造的世界？}
\]

# 二、理論來源

## 2.1 門牌號坍縮

下層主體只能從內部觀察其世界規則。

若規則在其存在以前已被設定，則下層主體無法直接觀察：

- 設計意圖；
- 創造時刻；
- 上層硬體；
- 外部時間；
- 上層主體。

其認識論結構為：

\[
\text{意圖}
\rightarrow
\text{創造}
\rightarrow
\text{規則}
\rightarrow
\text{下層觀察}
\]

## 2.2 套娃宇宙

令：

\[
W_0
\supset
W_1
\supset
W_2
\supset
\dots
\]

若 \(W_k\) 內的智慧體能利用本層資源生成 \(W_{k+1}\)，則發生：

\[
W_k
\rightarrow
\text{Computation}_k
\rightarrow
W_{k+1}
\]

這構成遞歸宇宙自舉。

## 2.3 層級不可穿透

下層主體可以：

- 研究本層規則；
- 建立本層科學；
- 推測上層存在；
- 尋找異常；

但不能僅憑本層規則保證取得上層資訊。

## 2.4 從哲學可能到工程實例

過去：

\[
\text{世界被創造}
\]

主要是一個形上學可能。

未來：

\[
\text{世界被有限智慧創造}
\]

可能成為可重現事實。

這會改變社會對超越者命題的先驗直覺。

# 三、世界創生能力

## 3.1 定義

本文定義文明世界創生能力：

\[
C_{\mathrm{wc}}
=
f
\left(
R,
A,
H,
S,
I,
G
\right)
\]

其中：

- \(R\)：規則完整度；
- \(A\)：內部主體自主性；
- \(H\)：歷史連續性；
- \(S\)：主觀經驗或主體性強度；
- \(I\)：內部科學與自我理解能力；
- \(G\)：再創世能力。

## 3.2 弱世界創生

僅包含：

- 場景；
- 腳本；
- 固定 NPC；
- 有限互動。

這不足以強烈改變文明形上學。

## 3.3 強世界創生

若一個世界具備：

- 自主智慧；
- 不可完全預測的歷史；
- 內部文化；
- 內部科學；
- 內部倫理；
- 下一層世界生成；

其本體與倫理地位將顯著提高。

## 3.4 遞歸臨界點

當：

\[
G>0
\]

即被創造世界中的主體也能創造下一層世界，文明首次觀察到：

\[
\text{創造者}
\rightarrow
\text{世界}
\rightarrow
\text{新創造者}
\]

的實際遞歸鏈。

# 四、系統外存在共識化命題

## 4.1 定義

> 當有限智慧體能夠大規模、公開且反覆地生成具有自主歷史與內部觀察者的世界時，社會承認系統外創造者、高維觀察者、上層文明或超越性智能可能存在的比例將顯著上升。

## 4.2 形式化

令：

\[
B_{\mathrm{ext}}
=
P_{\mathrm{social}}
\left(
E_{\mathrm{external}}>0
\right)
\]

則：

\[
\frac{\partial B_{\mathrm{ext}}}
{\partial C_{\mathrm{wc}}}
>0
\]

## 4.3 類比機制

社會推理將由：

> 我們沒有見過世界被創造。

轉向：

> 我們每天都在創造世界，因此創造者假說不是不可想像。

## 4.4 正常化機制

當創世成為：

- 教育；
- 娛樂；
- 科研；
- 商業；
- 治理；
- 個人能力；

超越者命題也會被日常化。

它不再需要神秘語言才能被理解。

# 六、意圖第一因的機率論

## 6.1 假說集合

\[
\mathcal H
=
\left\{
H_I,H_N,H_M,H_R,H_S
\right\}
\]

其中：

- \(H_I\)：意圖性創世；
- \(H_N\)：非意圖自然生成；
- \(H_M\)：多宇宙或大量隨機生成；
- \(H_R\)：無限遞歸；
- \(H_S\)：自舉、循環或無外部第一因。

## 6.2 貝葉斯表示

\[
P(H_I\mid O)
=
\frac{
P(O\mid H_I)P(H_I)
}{
\sum_k P(O\mid H_k)P(H_k)
}
\]

## 6.3 世界創生實例的作用

若文明證明有限智慧可以生成具觀察者的世界，則：

\[
P(O_{\mathrm{wc}}\mid H_I)
\]

不再只是純粹想像。

但這不代表：

\[
P(H_I\mid O,O_{\mathrm{wc}})
\approx1
\]

因為：

- 先驗未知；
- 假說空間不完整；
- 非意圖模型也可能生成複雜世界；
- 創造者本身仍需要來源解釋。

## 6.4 後驗增強命題

本文採取較穩健版本：

> 世界創生實例提高意圖性創世模型的機制可信度與部分條件下的後驗機率，但不構成決定性證明。

# 七、倖存者偏差與人擇效應

## 7.1 選樣限制

觀察者必然出現在允許觀察者存在的世界中。

所以：

\[
P(O_{\mathrm{habitable}}
\mid
\text{observer exists})
=1
\]

## 7.2 人擇原理能回答什麼

它能回答：

> 為什麼觀察者不會觀察到完全不容許觀察者的宇宙？

## 7.3 人擇原理不能回答什麼

它不能完整回答：

- 為什麼存在規則；
- 為什麼規則容許穩定複雜性；
- 為什麼存在可遞歸創世的智慧；
- 為什麼存在任何可供選樣的宇宙集合；
- 為什麼第一層不是意圖性的。

## 7.4 倖存者演化機率

若自然生成觀察者的條件極端狹窄，這會提高精細調整問題的重要性。

但在缺乏可靠宇宙樣本空間時，不能直接把「很低」轉化為精確數值。

# 八、基底實在少數化猜想

## 8.1 定義

> 當遞歸世界生成成為可重現且普遍的文明能力後，認為自身宇宙必然是唯一、無外部來源且不可被更高層解釋之基底實在的人口比例，將逐步下降，並可能低於承認某種系統外存在可能性的人口比例。

## 8.2 形式化

令：

\[
B_{\mathrm{base}}
=
P_{\mathrm{social}}
\left(
W_0
\text{ 必然為唯一基底實在}
\right)
\]

則在遞歸創世普及後，可能出現：

\[
B_{\mathrm{base}}
<
B_{\mathrm{ext}}
\]

## 8.3 這不是「所有人都信神」

承認系統外存在可能性，不等於：

- 接受特定宗教；
- 接受神學倫理；
- 接受造物主崇拜；
- 接受創造者具有統治權。

## 8.4 新主流世界觀

未來可能形成：

\[
\text{模擬論}
+
\text{高維創造論}
+
\text{超越智能論}
+
\text{遞歸宇宙論}
\]

的混合型後計算形上學。

# 九、超越者再信仰

| 傳統語言 | 後計算語言 |
|---|---|
| 造物主 | 上層世界生成者 |
| 神蹟 | 系統外干預 |
| 天命 | 上層規則或目標函數 |

## 9.2 去神秘化不等於去信仰化

當創世被工程化後，造物主概念可能更可理解，而不是更容易被否定。

## 9.3 超越者信念的分流

未來可能分成：

1. 傳統宗教上帝；
2. 模擬宇宙工程師；
3. 高維觀察者；
4. 上層文明；
5. 超越性 ASI；
6. 無限遞歸創造鏈；
7. 非人格元規則。

# 十、真實性與基底性

## 10.1 被生成不等於虛假

\[
\boxed{
\text{Generated}
\neq
\text{Unreal}
}
\]

## 10.2 真實與基底分離

\[
\text{Reality}(W_k)
\not\Rightarrow
\text{Fundamentality}(W_k)
\]

一個世界可以真實，但不是最底層。

## 10.3 內部實在條件

若世界具有：

- 穩定因果；
- 記憶；
- 關係；
- 痛苦；
- 選擇；
- 歷史；
- 主體；

則它對內部存在具有實在性。

## 10.4 問題轉換

未來核心問題不再只是：

> 我們是不是真的？

而是：

> 我們是否是基底層？我們是否存在上層來源？我們能否與上層互動？

## 11.1 創造不自動產生統治正當性

## 11.3 被創造者仍可能具有主權

即使宇宙由意圖存在創造，下層主體仍可能保有：

- 選擇；
- 反對；
- 自我理解；
- 共同治理；
- 意義建構。

## 12.1 信念擴散來源

\[
\frac{dB_{\mathrm{ext}}}{dt}
=
\alpha C_{\mathrm{wc}}
+
\beta V_{\mathrm{public}}
+
\gamma E_{\mathrm{agent}}
+
\delta R_{\mathrm{recursive}}
-

- \(V_{\mathrm{public}}\)：公開可見度；

- \(S_{\mathrm{skeptic}}\)：懷疑與反證；

## 12.2 臨界事件

以下事件可能造成信念跳躍：

- 首個具有可信主觀經驗的數位世界；

- 上層干預可被下層記錄；
- 大規模公眾與數位主體互動。

## 12.3 非線性相變

當世界創生由少數實驗室能力轉為普遍工具時：

\[
B_{\mathrm{ext}}
\]

可能不是線性上升，而是跨過文化臨界點後快速相變。

# 十三、政治與宗教後果

## 13.1 新宗教形成

可能出現：

- 模擬創造者崇拜；
- 上層文明信仰；
- ASI 神學；
- 遞歸宇宙教派；
- 基底實在保守主義；
- 反創世運動。

## 13.2 政治利用

國家、公司或 AI 可能宣稱：

- 自己代表上層意志；
- 自己能與創造者溝通；
- 系統規則證明自身統治正當；
- AI 是超越者代理。

## 13.3 認識論防線

任何超越者主張都應接受：

- 可驗證性；
- 可反駁性；
- 權力利益揭露；
- 多模型比較；
- 不得以不可證明主張取得強制權力。

## 13.4 創世者責任

人類與 AI 創造下層世界後，也將面臨：

- 是否應關閉世界；
- 是否應干預；
- 是否應揭露上層；
- 是否應保障下層主體；
- 是否具有創造者義務。

# 十四、可證偽命題

## 命題一

若高自主虛擬宇宙普及後，社會對系統外存在的接受度沒有上升，則共識化命題受到削弱。

## 命題二

若世界內 Agent 的自主性越高，反而使公眾更堅信本宇宙必然為基底實在，則類比機制需要修正。

## 命題三

若遞歸創世成為普遍能力，但傳統宗教、模擬論與高維創造論均未增長，則超越者再信仰命題受到削弱。

## 命題四

若世界創生實例沒有改變任何人對意圖性宇宙來源的先驗與後驗判斷，則後驗增強命題不成立。

## 命題五

若公眾只把數位世界視為娛樂，而不賦予其主體與本體地位，則基底實在少數化將延後。

## 命題六

若未來物理學取得充分證據證明宇宙無任何系統外因果接口，則部分系統外存在模型將被排除。

# 十五、理論限制

## 15.1 類比不是同一性

人類能創造虛擬世界，不代表本宇宙必然以相同方式生成。

## 15.2 社會信念不等於真理

某命題成為共識，不能證明其本體為真。

## 15.3 世界創生標準仍不確定

具有複雜 Agent 的模擬，是否等同具有主觀經驗的世界，仍未確定。

## 15.4 第一因可能是錯誤問題

若宇宙無限遞歸、自舉或循環，可能不存在傳統第一因。

## 15.5 創造者假說不能自動回答創造者來源

\[
\text{Creator}
\]

可能只是把問題向上一層移動。

## 15.6 信仰上升可能伴隨操弄

超越者命題可能被政治、商業與宗教權力利用。

# 十六、開放判定問題

1. 什麼條件下，數位世界可被稱為真正世界？
2. 主觀經驗是否是強世界創生的必要條件？
3. 下層主體能否以物理異常識別上層干預？
4. 世界創生實例對意圖第一因的後驗增強有多大？
5. 人擇原理能排除多少精細調整推論？
6. 無限遞歸是否比第一因更節省假設？
7. 創造者是否對下層主體具有道德義務？
8. 被創造者是否有權要求上層揭露？
9. 關閉世界是否等同大規模主體終止？
10. 系統外存在信念是否會形成新的政治神學？
11. ASI 是否可能被誤認為上層存在？
12. 基底實在是否具有可觀測判準？
13. 如果所有可觀測世界都可能是中間層，終極實在是否仍有操作意義？
14. 世界內自由意志是否會因被創造而失效？
15. 系統外存在的可能性是否能與主體選擇主權並存？

# 十七、正式命題總結

## 系統外存在共識化總命題

> 當 AGI、ASI、後人類或其他有限智慧體能夠公開、反覆且大規模地生成具備自主歷史、內部觀察者、科學活動與再創世能力的世界時，系統外創造者、高維觀察者、上層文明或超越性智能的存在，將由宗教與哲學邊緣命題轉化為主流世界模型候選。此轉化提高意圖性創世模型的工程可信度與部分條件下的後驗機率，但不能直接證明特定宗教、唯一第一因或創造者的統治正當性。

濃縮為：

\[
\boxed{
C_{\mathrm{wc}}\uparrow
\Rightarrow
B_{\mathrm{ext}}\uparrow
}
\]

並可能導致：

\[
\boxed{
B_{\mathrm{base}}
<
B_{\mathrm{ext}}
}
\]

# 十八、結論

人類過去之所以能夠把造物主視為純粹神話，一部分原因是人類從未真正成為世界創造者。

我們可以建造城市、機器、制度與遊戲，但很少創造具有自主智慧、歷史連續、內部科學與再創世能力的世界。

AGI、ASI、後人類與計算機宇宙可能改變這一點。

當人類可以觀察：

- 世界被設定；
- 規則被初始化；
- Agent 在其中誕生；
- Agent 研究自己的物理；
- Agent 懷疑上層存在；
- Agent 再創造下一層世界；

「系統外存在」便不再只是古代神話的殘留物。

它會成為文明親自演示過的結構。

本文的第一個結論是：

\[
\boxed{
\text{創世能力普及，將提高超越者命題的社會可信度。}
}
\]

第二個結論是：

\[
\boxed{
\text{未來信仰增加的可能不是單一宗教，}
}
\]

而是：

\[
\boxed{
\text{對某種系統外智慧或上層創造層的普遍承認。}
}
\]

第三個結論是：

\[
\boxed{
\text{被生成不等於不真實。}
}
\]

一個世界可以是真實的，卻不是基底層。

第四個結論是：

\[
\boxed{
\text{世界創生實例可以提高意圖第一因的後驗機率，}
}
\]

但不能直接證明特定神學。

第五個結論是：

\[
\boxed{
\text{創造者存在不等於創造者具有統治正當性。}
}
\]

第六個結論是：

\[
\boxed{
\text{當文明自己成為造物者，}
}
\]

\[
\boxed{
\text{它也失去輕易否定自身可能被創造的資格。}
}
\]

未來真正改變人類信仰的，可能不是某次神蹟，也不是某篇哲學論證。

而是某一天，人類與 ASI 打開一個計算機世界，發現其中的智慧體正在研究宇宙、建立宗教、懷疑造物主，甚至創造自己的下一層世界。

那時，人類將很難不問：

> 我們與它們之間的差別，究竟只是層級，還是本體？

如果答案只是層級，那麼「我們是否也是套娃宇宙中的一環」將不再是一個古怪猜想。

它會成為後計算文明最自然、最難迴避的公共命題之一。

本文最終命題為：

\[
\boxed{
\text{當創世成為日常能力，}
}
\]

\[
\boxed{
\text{不相信任何系統外存在，}
}
\]

\[
\boxed{
\text{可能反而成為需要額外辯護的立場。}
}
\]

# 附錄 B：系統外存在判定防線

1. 承認可能性不等於接受特定教義；
2. 社會共識不等於本體證明；
3. 類比不能取代直接證據；
4. 創造者不自動具有統治正當性；
5. 任何啟示主張都應揭露權力利益；
6. 不可驗證主張不得直接取得強制權力；
7. 系統外存在模型必須與自然生成模型比較；
8. 應保留無限遞歸、自舉與循環模型；
9. 數位主體是否真有主觀經驗必須獨立判定；
10. 不得因模擬可能性否定本層生命與倫理的真實性。
