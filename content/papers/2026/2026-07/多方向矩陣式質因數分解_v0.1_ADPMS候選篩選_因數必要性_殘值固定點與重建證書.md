## 摘要

傳統質因數分解通常被描述為：對目標整數 \(N\) 尋找一個非平凡因數，將 \(N\) 分裂，再遞迴分解剩餘部分。此描述重視最終因數，卻較少保存候選如何生成、如何被排除、哪些候選已成為必要因數、哪些測試因殘值更新而失效，以及不同計算路徑如何收斂至同一唯一分解。

本文提出「多方向矩陣式質因數分解」（Multidirectional Matrix Prime Factorization, MMPF）。其核心不是宣稱發明新的快速大整數分解法，而是將質因數分解重新表示為：

\[
\boxed{
\text{候選生成}
\rightarrow
\text{多軸篩選}
\rightarrow
\text{候選狀態收縮}
\rightarrow
\text{殘值下降}
\rightarrow
\text{指數固定}
\rightarrow
\text{重建與證書}
}
\]

本文保留舊版 ADPMS 中可操作的部分：利用 \(6k\pm1\) 生成候選、維護動態質數乘數集合、只檢查不超過平方根的候選，並將 ADPMS 重新定位為 MMPF 的前端候選篩選器，而不是完整分解演算法。

對每個候選質數 \(p\)，本文不只記錄 \(N\bmod p\)，而維護其指數區間：

\[
I_p(t)
=
[
\underline v_p(t),
\overline v_p(t)
].
\]

候選可處於：

- `EXCLUDED`：確定不需要；
- `POSSIBLE`：仍可能需要；
- `REQUIRED`：至少需要一次；
- `FIXED`：完整重數已確定。

本文進一步定義質因數分解過程空間：

\[
\Omega(N)
=
\{
\pi_1,\pi_2,\ldots
\},
\]

其中不同路徑可以使用不同候選順序、分區、模篩、殘值更新與硬體配置，但所有正確路徑最終必須收斂至算術基本定理給出的唯一質因數多重集合。

本文將 3M 系列重新分工：

- **MLF**：保存候選、矩陣、路徑、來源與轉換損失；
- **MMLC**：執行多方向遍歷、約束傳播、殘值下降與指數固定；
- **MMR**：比較遍歷方向、重播排除過程並輸出簽章分解證書。

固定點纖維理論則提供殘值下降結構。令：

\[
T_{\min}(n)
=
\min\{d>1:d\mid n\},
\]

則：

\[
\operatorname{Fix}(T_{\min})
=
\mathbb P.
\]

若能證明某殘值 \(r_t\) 本身為固定點，則該殘值即為最後質因數，其餘大於 \(\sqrt{r_t}\) 的候選可直接終止。

本文的核心主張為：

> 質因數分解不只是一個最終乘積等式，也是一個可被矩陣化、分支化、平行化、審計化與證書化的候選知識收縮過程。

# 一、問題重新定義

## 1.1 質因數分解的答案唯一，過程不唯一

對任意整數：

\[
N>1,
\]

存在唯一質因數分解：

\[
N
=
\prod_{p\in\mathbb P}
p^{v_p(N)},
\]

其中只有有限多個 \(v_p(N)\) 非零。

因此，本文不主張 \(N\) 有多個不同的正確質因數分解。

真正具有大量可能性的是：

- 候選生成順序；
- 試除順序；
- 模篩順序；
- 分支順序；
- 區塊切分；
- 中間合數分割；
- 殘值更新順序；
- 平行核心配置；
- 提前停止策略；
- 排除證明方式。

所以本文研究：

\[
\boxed{
\text{唯一結果下的多路徑計算空間。}
}
\]

---

## 1.2 質因數分解過程空間

定義：

\[
\Omega(N)
=
\{
\pi:
\pi\text{ 是一條合法候選篩選與殘值下降路徑}
\}.
\]

每條路徑可表示為：

\[
\pi
=
(
C_0,
\mathcal T_0,
r_0,
C_1,
\mathcal T_1,
r_1,
\ldots,
C_T,
r_T
),
\]

其中：

- \(C_t\)：第 \(t\) 輪候選集合；
- \(\mathcal T_t\)：本輪測試與約束；
- \(r_t\)：本輪殘值；
- \(r_0=N\)；
- \(r_T=1\) 或 \(r_T\) 已被證明為質數。

---

## 1.3 從「找因數」改成「維護候選知識」

傳統最簡描述：

```text
尋找 p，使 N mod p = 0。
```

MMPF 改為：

```text
對每個候選 p：
  它是否仍可能出現？
  它是否已必然出現？
  它需要幾次？
  哪些路徑仍依賴它？
  哪些測試已足以排除它？
  哪些殘值更新使舊結論失效或變得多餘？
```

因此核心資料不是單一餘數，而是：

\[
\boxed{
\text{候選因數的認識狀態。}
}
\]

---

# 二、ADPMS 的重新定位

## 2.1 保留的概念

ADPMS 保留以下結構：

1. 先處理 \(2,3\)；
2. 對大於 \(3\) 的候選使用 \(6k\pm1\)；
3. 維護已確認質數集合；
4. 對候選只檢查不超過其平方根的已知質數；
5. 新質數被加入後續動態乘數集合。

初始候選可寫為：

\[
C_6(B)
=
\{2,3\}
\cup
\{
n\le B:
n\equiv\pm1\pmod6
\}.
\]

---

## 2.2 不保留的主張

本框架不直接繼承：

- 「模六揭示質數非隨機本質」；
- 「張力場」作為演算法證明；
- 未附完整基準條件的速度倍數；
- ADPMS 已優於所有主流篩法；
- 模 \(6\) 足以解決一般大整數分解。

ADPMS 在本文中的位置是：

\[
\boxed{
\operatorname{ADPMS}
=
\text{候選生成器}
+
\text{初級篩選器}.
}
\]

---

## 2.3 高階模輪

候選生成可以從模 \(6\) 推廣到 wheel：

\[
W_m
=
\{
a\in\{0,\ldots,m-1\}:
\gcd(a,m)=1
\}.
\]

例如：

\[
m=30
\]

時：

\[
W_{30}
=
\{1,7,11,13,17,19,23,29\}.
\]

但模輪越大：

- 候選比例越低；
- 建表與遍歷成本越高；
- 記憶區域更複雜；
- 對單一 \(N\) 的實際收益需實驗判斷。

因此 MMPF 允許多個模層並行存在，而不是預設越高模數越好。

# 三、候選必要性理論

## 3.1 指數函數

對候選質數 \(p\)，質因數重數為：

\[
v_p(N)
=
\max
\{
e\in\mathbb N:
p^e\mid N
\}.
\]

最終任務是求出所有非零：

\[
v_p(N).
\]

---

## 3.2 指數區間

在第 \(t\) 輪，維護：

\[
I_p(t)
=
[
\underline v_p(t),
\overline v_p(t)
].
\]

必須滿足：

\[
0
\le
\underline v_p(t)
\le
v_p(N)
\le
\overline v_p(t).
\]

合法更新應使：

\[
\underline v_p(t+1)
\ge
\underline v_p(t),
\]

\[
\overline v_p(t+1)
\le
\overline v_p(t).
\]

因此區間只能收縮，不能無證據擴張。

---

## 3.3 四種狀態

### `EXCLUDED`

\[
I_p(t)
=
[0,0].
\]

即：

\[
v_p(N)=0.
\]

### `POSSIBLE`

\[
0
=
\underline v_p(t)
<
\overline v_p(t).
\]

候選仍未排除，但尚未證明必要。

### `REQUIRED`

\[
1
\le
\underline v_p(t)
<
\overline v_p(t).
\]

候選至少需要一次，但完整重數尚未固定。

### `FIXED`

\[
\underline v_p(t)
=
\overline v_p(t)
=
v_p(N).
\]

---

## 3.4 路徑語義

對存活路徑集合：

\[
\Omega_t(N)
\subseteq
\Omega(N),
\]

候選 \(p\) 為必要因數當且僅當：

\[
\forall\pi\in\Omega_t(N),
\quad
v_p(\pi)>0.
\]

候選 \(p\) 被排除當且僅當：

\[
\forall\pi\in\Omega_t(N),
\quad
v_p(\pi)=0.
\]

候選仍可能當且僅當：

\[
\exists\pi_1,\pi_2\in\Omega_t(N)
\]

使：

\[
v_p(\pi_1)>0,
\qquad
v_p(\pi_2)=0.
\]

# 四、三類核心矩陣

## 4.1 候選—殘值矩陣

令候選集合為：

\[
P_c
=
\{p_1,\ldots,p_m\},
\]

殘值集合為：

\[
R
=
\{r_0,\ldots,r_n\}.
\]

定義：

\[
A_{ij}
=
r_j\bmod p_i.
\]

若：

\[
A_{ij}=0,
\]

則 \(p_i\) 整除殘值 \(r_j\)。

這個矩陣可以：

- 按候選列並行；
- 按殘值欄並行；
- 按區塊分片；
- 在發現因數後增量更新。

---

## 4.2 候選—路徑矩陣

定義：

\[
B_{ik}
=
\begin{cases}
0,&p_i\text{ 不出現在路徑 }\pi_k,\\
1,&p_i\text{ 至少出現一次},\\
e,&p_i\text{ 在路徑中重數為 }e.
\end{cases}
\]

此矩陣回答：

- 某候選是否出現在所有存活路徑；
- 某候選是否只出現在少數分支；
- 哪些路徑因排除某候選而同時失效。

---

## 4.3 候選—約束矩陣

設約束集合：

\[
\mathcal C
=
\{
c_1,\ldots,c_\ell
\}.
\]

定義：

\[
C_{i\ell}
\in
\{
\text{PASS},
\text{FAIL},
\text{UNKNOWN}
\}.
\]

約束可包括：

- 模 \(6\)；
- 模 \(30\)；
- 模 \(210\)；
- 大小界；
- 平方根界；
- 乘積界；
- 已知因數互質性；
- 殘值界；
- 重數界；
- 固定點檢查；
- 外部素性證書。

---

## 4.4 多矩陣而非單一高維張量

MMPF 不強迫所有資訊放入一個巨大 tensor。

更符合 3M 的表示是：

\[
\boxed{
\text{具型別矩陣}
+
\text{依賴圖}
+
\text{路徑帳本}
+
\text{證書索引}.
}
\]

# 五、殘值固定點下降

## 5.1 最小非平凡因數算子

定義：

\[
T_{\min}(n)
=
\min
\{
d\in\mathbb N:
d>1,\ d\mid n
\}.
\]

其固定點為質數：

\[
\operatorname{Fix}(T_{\min})
=
\mathbb P.
\]

---

## 5.2 殘值下降

令：

\[
r_0=N.
\]

若已確認：

\[
p_t
=
T_{\min}(r_t),
\]

則：

\[
r_{t+1}
=
\frac{r_t}{p_t}.
\]

反覆執行直到：

\[
r_T=1.
\]

或在某一步證明：

\[
T_{\min}(r_t)=r_t,
\]

此時 \(r_t\) 為質數，可作為最後因數。

---

## 5.3 重要限制

計算：

\[
T_{\min}(n)
\]

本身就是最小質因數搜尋問題。

因此固定點下降提供：

- 結構；
- 終止條件；
- 纖維標記；
- 路徑語義；

但不免費提供快速求解器。

MMPF 的任務是用候選矩陣與約束傳播逐步證明：

\[
T_{\min}(r_t)=p_t.
\]

---

## 5.4 平方根終止

若對殘值 \(r_t>1\) 已排除所有：

\[
p\le\sqrt{r_t},
\]

則：

\[
r_t
\]

必為質數。

因此可以直接加入：

\[
v_{r_t}(N)\leftarrow v_{r_t}(N)+1,
\]

並令：

\[
r_{t+1}=1.
\]

## 6.3 偽碼

```text
Algorithm MMPF(N)

input:
  integer N > 1

state:
  residual r ← N
  factor ledger V ← {}
  candidate registry C ← ADPMS_generate(isqrt(r))
  evidence log E ← []
  route graph G ← empty

while r > 1:

  if primality_certificate(r) succeeds:
      V[r] ← V.get(r, 0) + 1
      record FIXED(r, multiplicity=1)
      r ← 1
      break

  active ← candidates p in C with p ≤ isqrt(r)

  evaluate modular and divisibility constraints
  in parallel or by selected matrix traversal

  if no active candidate divides r:
      V[r] ← V.get(r, 0) + 1
      record residual-prime certificate
      r ← 1
      break

  choose a proven divisor p

  e ← 0
  while r mod p = 0:
      r ← r / p
      e ← e + 1

  V[p] ← V.get(p, 0) + e
  update lower and upper valuation bounds
  mark p FIXED for this residual stage

  invalidate or shrink obsolete candidate regions
  regenerate candidate bound for new residual
  append transition and provenance event

verify:
  product over p^V[p] equals N
  every listed p is prime
  every transformation replays

return:
  factors V
  process ledger
  reconstruction certificate
```

# 七、平行化不是單一形式

## 7.1 候選平行

將候選質數分區：

\[
P_c
=
P_1
\sqcup
P_2
\sqcup
\cdots
\sqcup
P_s.
\]

各 worker 對同一殘值執行除法或模測試。

---

## 7.2 殘值平行

當分解已產生多個合數殘值：

\[
N
=
a_1a_2\cdots a_k,
\]

可以平行分解：

\[
a_1,\ldots,a_k.
\]

---

## 7.3 模層平行

同時執行：

- mod \(6\)；
- mod \(30\)；
- mod \(210\)；
- 其他局部模條件。

再由約束交集縮減候選。

---

## 7.4 路徑平行

不同策略同時執行：

- 最小候選優先；
- 大區塊試除；
- 隨機候選；
- 結構性分割；
- 外部因數器；
- 素性證明。

MMR 比較其：

- 成本；
- 淘汰率；
- 首因數時間；
- 證書大小；
- 重播穩定性。

---

## 7.5 重要警告

平行可表示不等於平行必加速。

實際加速受：

- 記憶頻寬；
- 任務粒度；
- 通信；
- 分支不平衡；
- 除法成本；
- 早停；
- worker 重複工作；

限制。

## 9.2 證書能證明什麼

有效證書可以證明：

1. 最終質因數乘積等於原始 \(N\)；
2. 每個列出的因數通過指定素性驗證；
3. 重數與殘值下降可重播；
4. 原始資料與證書雜湊一致；
5. 執行帳本未被無痕修改。

---

## 9.3 證書不能證明什麼

它不自動證明：

- 使用的是理論最優算法；
- 過程是最快路徑；
- 所有排除測試都有必要；
- 實現沒有側通道；
- 任何密碼系統因此安全；
- 矩陣化一定帶來複雜度突破。

# 十、候選淘汰規則

## 10.1 直接不整除

若：

\[
r_t\bmod p\neq0,
\]

則 \(p\) 不是當前殘值的因數。

但若處理的是原始 \(N\) 的全域候選，仍需考慮 \(p\) 是否已在先前殘值中被提取。

---

## 10.2 平方根淘汰

若：

\[
p>\sqrt{r_t},
\]

且尚未找到小因數，則 \(p\) 不需要繼續試除當前殘值。

---

## 10.3 殘值縮小淘汰

殘值從：

\[
r_t
\]

降為：

\[
r_{t+1},
\]

所有：

\[
p>\sqrt{r_{t+1}}
\]

的候選區域可被標記為對新殘值不必要。

---

## 10.4 指數上界

對候選 \(p\)：

\[
\overline v_p
\le
\left\lfloor
\log_p N
\right\rfloor.
\]

若已提取 \(e\) 次，則剩餘上界為：

\[
\overline v_p^{remain}
\le
\left\lfloor
\log_p r_t
\right\rfloor.
\]

---

## 10.5 乘積界

若已知未固定候選最小可能乘積已超過殘值，對應路徑可直接淘汰。

---

## 10.6 互斥與依賴

若分支假設：

\[
r_t=ab
\]

要求某候選集合，但其中一個必要候選已被排除，整條分支可淘汰。

---

# 十一、固定點纖維視角

## 11.1 纖維

令：

\[
F_p
=
T_{\min}^{-1}(p).
\]

則：

\[
F_p
\]

包含所有最小質因數為 \(p\) 的整數。

---

## 11.2 候選路由

ADPMS 與矩陣篩選的第一個主要任務是判定：

\[
r_t\in F_p
\]

對哪個 \(p\) 成立。

一旦證明：

\[
r_t\in F_p,
\]

便得到：

\[
p=T_{\min}(r_t).
\]

---

## 11.3 纖維下降鏈

分解可寫為：

\[
r_0
\in
F_{p_0},
\]

\[
r_1
=
r_0/p_0
\in
F_{p_1},
\]

直到：

\[
r_T=1.
\]

因此：

\[
N
=
p_0p_1\cdots p_{T-1}.
\]

將相同質數合併即可得到標準重數形式。

# 十四、複雜度與誠實邊界

## 14.1 ADPMS 的候選縮減

模 \(6\) 候選比例約為：

\[
\frac{2}{6}
=
\frac13.
\]

這只說明相對於遍歷全部整數，候選數量降低。

它不等於一般整數分解複雜度下降至多項式。

---

## 14.2 矩陣化的成本

設候選數為 \(m\)，殘值或分支數為 \(n\)。

完整候選—殘值矩陣大小可達：

\[
O(mn).
\]

若不採稀疏、區塊與增量更新，矩陣化反而可能增加成本。

---

## 14.3 平行上界

假設有 \(s\) 個 worker，理想候選試除加速不超過：

\[
s.
\]

實際速度還需扣除：

- 切分；
- 通信；
- 結果合併；
- 早停不平衡；
- 記憶競爭；
- 重複候選。

---

## 14.4 本文不宣稱

本文不宣稱：

- 破解 RSA；
- 打破 NFS 漸近界；
- ADPMS 優於所有質數篩；
- 矩陣化必然加速；

# 十七、形式不變量

MMPF 執行過程至少維持：

## I1：來源積不變量

若已固定因數乘積為：

\[
F_t
=
\prod_p p^{e_p(t)},
\]

則：

\[
N
=
F_t\cdot r_t.
\]

## I2：殘值整除不變量

\[
r_t\mid N.
\]

## I3：殘值下降

每次成功提取後：

\[
r_{t+1}<r_t.
\]

## I4：指數區間正確性

\[
\underline v_p(t)
\le
v_p(N)
\le
\overline v_p(t).
\]

## I5：排除不可逆性

若候選被標記 `EXCLUDED`，必須存在可重播證據；否則不得刪除。

## I6：固定正確性

若候選標記 `FIXED`，其上下界必須相等。

## I7：最終重建

\[
\prod_p p^{v_p(N)}
=
N.
\]

## I8：素性

所有最終底數必須有素性證據。

# 十八、失敗模式

## 18.1 把候選當因數

\(6k\pm1\) 只是候選條件，不是素性證明。

## 18.2 把矩陣當加速保證

矩陣表示改善可審計性，不自動改善時間複雜度。

## 18.3 無界分支

保存所有可能路徑會造成組合爆炸。

## 18.4 舊殘值污染

殘值更新後，舊候選判定被錯誤套用到新狀態。

## 18.5 無證排除

為節省空間刪除候選，卻未保留排除原因。

## 18.6 素性與整除混淆

找到整除者不表示它本身為質數。

## 18.7 證書過度宣稱

重建正確不等於算法最優。

## 18.8 多 worker 重複

平行 worker 在早停前執行大量重複除法。

## 18.9 分支共識幻覺

多條使用相同假設的路徑不構成獨立證據。

---

# 十九、可證偽條件

MMPF 應接受以下檢驗：

1. 候選矩陣是否能減少不必要測試；
2. 指數區間是否能比單純 factor list 更早表達部分結果；
3. row、column、block 遍歷是否有可測差異；
4. MLF 保存成本是否低於其審計價值；
5. MMLC 約束傳播是否能提前淘汰候選；
6. MMR replay 是否能發現被竄改的排除事件；
7. 平行化收益是否高於通信與重複成本；
8. 固定點纖維標記是否改善路由；
9. 對半質數，MMPF 是否只是昂貴的試除包裝；
10. 與 Pollard rho、ECM、QS 相比，MMPF 的實際角色是加速器、協調器，還是純證書層。

若結果顯示：

- 候選矩陣只增加記憶；
- 約束傳播沒有額外排除；
- replay 成本過高；
- 分支表示不提供可用資訊；

則應縮小 MMPF 的主張，將其定位為證書與研究格式，而不是分解框架。

# 二十一、核心命題

## 命題 1：結果唯一、過程多樣

質因數分解結果由算術基本定理唯一決定，但計算路徑可有多種。

## 命題 2：候選狀態可單調收縮

合法證據應使指數下界不下降、上界不上升。

## 命題 3：殘值下降提供終止結構

成功提取質因數後，殘值嚴格下降；殘值為質數時達到固定點終止。

## 命題 4：多矩陣優於單矩陣

候選、殘值、路徑、約束與證書應使用具型別多矩陣與圖，而非無差別高維陣列。

## 命題 5：3M 是分工系統

MLF 保存、MMLC 執行、MMR 驗證。

## 命題 6：矩陣化不等於複雜度突破

任何速度優勢都必須由基準實驗證明。

## 命題 7：MMPF 首先是過程框架

MMPF 的第一價值是：

- 表示；
- 路由；
- 審計；
- 比較；
- 證書。

其是否成為新型高效因數器，仍是開放實驗問題。

# 二十二、結論

本文將質因數分解從：

\[
\text{尋找一個因數}
\]

重構為：

\[
\boxed{
\text{維護所有候選因數的必要性、可能性、排除性與重數區間。}
}
\]

ADPMS 在此不再承擔完整分解，而作為：

\[
\boxed{
\text{模輪候選生成與動態初篩層。}
}
\]

固定點纖維理論提供：

\[
\boxed{
\text{殘值所屬最小質因數纖維與質數固定點終止結構。}
}
\]

3M 則提供：

\[
\boxed{
\text{MLF 保存}
\rightarrow
\text{MMLC 執行}
\rightarrow
\text{MMR 驗證}
}
\]

完整流程為：

\[
\boxed{
N
\rightarrow
C_0(N)
\rightarrow
(A,B,C)
\rightarrow
I_p(t)
\rightarrow
r_{t+1}
\rightarrow
v_p(N)
\rightarrow
\prod p^{v_p(N)}=N
\rightarrow
\text{Certificate}
}
\]

因此，MMPF v0.1 的準確定位是：

> 一種將質因數分解轉換為多方向候選矩陣、殘值下降、約束傳播與可重播證書的通用計算框架。

它目前不是新的複雜度突破，也不是現有大整數因數算法的替代品。

但它提供了一個現有因數器普遍缺少的層次：

\[
\boxed{
\text{整個分解過程如何被保存、比較、平行調度與證明。}
}
\]

下一步不應繼續擴張理論，而應直接實作：

1. `adpms_filter.py`；
2. 候選—殘值矩陣；
3. 指數區間帳本；
4. 三種遍歷方向；
5. JSON 重建證書；
6. 第一輪 MMPF-Bench。
