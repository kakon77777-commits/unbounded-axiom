Main claims:
- Raw traffic count is insufficient for mixed human/agent network activity.
- Machine Attention is a semantic-resource-allocation subset of Machine Traffic.
- Traffic events should be typed by Actor, Intent, Depth, Utility, Conversion, Persistence, Downstream Reach, and Time.
- Same request count can have different economic/informational value.
- Machine traffic supports a distinct discovery-to-invocation-to-payment funnel.
- Attention Economy is better extended to Dual Attention and Executable Attention rather than simply replaced.
