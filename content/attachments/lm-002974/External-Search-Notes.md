# External Search Notes — Unified Ontology Synthesis v1.0

A fresh web search was performed immediately before this synthesis.

Primary external comparison sources retained in v1.0:

1. Leo Lobski & Fabio Zanasi, `Layered Monoidal Theories I: Diagrammatic Algebra and Applications`, arXiv:2602.19776 (2026).
   - multiple abstraction levels;
   - explicit translations between theories;
   - used only as a comparison for layered/translation-aware formalization.

2. Leo Lobski & Fabio Zanasi, `Layered Monoidal Theories II: Fibrational Semantics`, arXiv:2602.22373 (2026).
   - fibrational, opfibrational and deflational semantics;
   - connection to Grothendieck fibrations / displayed categories.

3. Benedikt Ahrens & Peter LeFanu Lumsdaine, `Displayed Categories`, arXiv:1705.04296 (2017).
   - modularly add data/properties over a base category;
   - comparison for vertical spine + cross-cut modular organization.

4. Robert E. Kent, `The Institutional Approach`, arXiv:1810.08074 (2018).
   - ontology integration through local logics, mappings, institutions and indexed/fibrational ideas.

5. Max Willsey et al., `egg: Fast and Extensible Equality Saturation`, arXiv:2004.03082 (2020).
   - e-graphs compactly store congruence/equivalence classes;
   - comparison for CRL's separation between equivalence storage and later extraction/routing.

Boundary:
These papers do not prove the EveMissLab ontology, the E/L/C triad's universality, Phi_pre, SSDC universality, CRL endogeneity, or UMF as a physical Theory of Everything.
