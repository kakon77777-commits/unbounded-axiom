# VALIDATION_PROTOCOL — GCORF-08 v0.1

## Multi-observer validation

1. Define source object and corpus
2. Define coupling-condition matrix
3. Run independent reconstructions
4. Record observer diversity profile
5. Align operators
6. Strip implementation modes where justified
7. Normalize translations where required
8. Build validation matrix
9. Preserve disagreements
10. Run negative controls
11. Run adversarial / red-team observers
12. Estimate cross-coupling stability
13. Extract CIK
14. Record novel branches
15. Assign validation level V0–V6
16. Set reopen triggers

## Validation levels

- V0: single reconstruction
- V1: repeat same condition
- V2: protocol diversity
- V3: observer diversity
- V4: corpus diversity
- V5: adversarial / negative-control validation
- V6: cross-coupling stable kernel

## Never infer

- consensus => truth
- V6 => truth
- model count => independence
- stable core => true internal mind mechanism
