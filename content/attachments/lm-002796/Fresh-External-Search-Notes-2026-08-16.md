# Fresh external search notes — 2026-08-16

Fresh search was performed before drafting EML-RKD-02.

These sources are methodological precedents and comparison points only. None proves the RKD algebra.

## Primary sources

1. Benedikt Ahrens & Peter LeFanu Lumsdaine, *Displayed Categories*, arXiv:1705.04296.
   - Displayed categories organize additional data/properties as families indexed over base objects.
   - Used only as a precedent for typed/dependent higher-level structure rather than forcing all levels into one homogeneous carrier.

2. Michael T. Cox et al., *Computational Metacognition*, arXiv:2201.12885.
   - Represents and monitors traces of cognition in artificial cognitive systems and uses meta-level operations to alter cognition.
   - Used as a precedent that meta-level cognitive organization can have non-human computational realizations.

3. Miklós Pintér, *Every hierarchy of beliefs is a type*, arXiv:0805.4007.
   - Formal higher-order belief hierarchies in a purely measurable type-space framework.
   - Used only to motivate explicit inter-level coherence; belief is not identified with knowing.

4. Benedikt Ahrens, Peter LeFanu Lumsdaine & Vladimir Voevodsky, *Categorical structures for type theory in univalent foundations*, arXiv:1705.04310.
   - Compares structured categorical semantics for dependent type theories.
   - Used as a general typed-structure precedent.

## Deliberate non-use
No secondary articles or blogs were used as premises.
No external source is cited as proving that meta-residual = metacognition, or that K/F is a universal cognitive architecture.
