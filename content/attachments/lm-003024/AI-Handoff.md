# AI_HANDOFF — Series 06

核心：DGF = Domain Genesis Framework.

不可破壞：
1. NoDomain != NoStructure
2. Domain is not automatically fundamental ontology
3. Domain projection must record observer/question/policy
4. UsefulDomain != FundamentalDomain
5. Class != Domain
6. Bridge != Identity
7. StableDomain != FundamentalOntology
8. MetaDomain != HigherTruth
9. Unknown / residual must be preserved
10. Projected domain should preserve deprojection lineage when possible
11. Domain can be discovered/projected/constructed/hybrid/unknown
12. Premature Ontologization is a failure mode
13. Domain registry != world ontology
14. Subject and domain registry co-evolve
