# TRANSLATION_PROTOCOL — GCORF-07 v0.1

## Translation admission

1. Define translation demand
2. Define source / target bottom spaces
3. Define invariant set
4. Mark hard / soft invariants
5. Search / define bridge operators
6. Execute translation
7. Measure loss vector
8. Run round-trip or domain-appropriate transfer test
9. Recompute SBL
10. Re-audit failures
11. Re-audit observer conditions
12. Re-audit license
13. Decide:
    - ExactWithinScope
    - Lossy
    - Supertranslated
    - Forked
    - NewOperator
    - Failed
    - Unknown

## Supertranslation additional gate

- novelty trace
- identity audit
- operator admission if new kernel emerges

## Required invariants

- provenance
- explicit loss
- no license inheritance
- path traceability
- recertification
