Canonical distinctions:

- Convergence != Fixed Point
- Fixed Point != Closure
- Local Closure != Global Closure
- Closure != Commit
- Branch Validity != Branch Priority
- CRL != Forced Consensus
- CRL != Bare Closure
- CRL is not assumed to equal Link o Converge
- Certified Global Closure is scope/identity/boundary/information/certificate relative
- Closure may be reopened under regime change

Canonical new object:

`CRE = Closure–Relinking Extension`

CRE is an enriched extension, not a proof that CRL is derivable from bare Closure.
