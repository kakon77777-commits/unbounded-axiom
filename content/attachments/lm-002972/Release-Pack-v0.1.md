# Ontology Canon v0.1 Release Pack

這個 ZIP 為 EveMissLab Ontology Canon v0.1 的乾淨 UTF-8 原始碼套件。

包含：
- `EveMissLab_Ontology_Canon_v0.1_2026-08-15.md`
- `PROVENANCE_NOTES.md`
- `validation.json`
- `CHECKSUMS.sha256`

格式規則：
- UTF-8（無 BOM）
- 數學只使用 `$...$` 與 `$$...$$`
- 不做 LaTeX → Unicode 數學符號 round-trip
- 聊天介面的 `filecite` 標記未寫入正典正文，以避免離線文件出現不可攜 UI 標記
- 歷史來源將在下一份 `Ontology Genealogy & Symbol Migration Map v0.1` 中正式逐條映射

本包是 Working Canon，不代表所有 open relations 已經被證明。
