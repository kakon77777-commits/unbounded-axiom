# OBSERVER_PROTOCOL — GCORF-06 v0.1

## Observer admission

1. Define target scope
2. Define frame
3. Audit access
4. Define operator set
5. Define evidence policy
6. Define known limits
7. Define known blind spots
8. Build observer SBL
9. Cross-observer test
10. Admit / Provisional / Reject

## Meta-observer extension

1. State new observation demand
2. Create candidate O^(n+1)
3. Legal_O audit
4. Incremental gain test
5. New-error audit
6. Cost audit
7. Progress_O decision
8. Commit / Reject / Defer

## Stop conditions

- marginal gain below threshold
- cost above threshold
- risk above threshold
- deadline / deployment need
- stable sufficient answer
- unresolved uncertainty explicitly preserved

## Required invariants

- finite-prefix actuality
- no higher-layer authority shortcut
- observer provenance
- blind-spot preservation
- disagreement preservation
- reopenability
