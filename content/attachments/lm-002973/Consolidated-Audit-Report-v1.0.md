# 3. What Was Retired

91 條 RETIRE 主要分成八類：

1. **Type jump**：semantic/generalized phase 無映射升格為 PH-0。
2. **Representation → ontology jump**：可表示不等於本體身份。
3. **Analogy → isomorphism jump**：mapping table 不等於同構。
4. **Frequency coincidence → coupling jump**：頻率接近不等於相互作用。
5. **Correlation / efficacy → mechanism jump**：效果不證明指定機制。
6. **Hidden computation → O(1)**：前處理／索引／拓樸計算不能被藏掉。
7. **Continuous space → hypercomputation**：不可數 state space 不等於 exact real input access。
8. **Engineering phase → quantum phase**：多相、PLL、resonance 不等於量子相位。

# 4. Five Core Audit Principles

## Principle A — Type Before Transfer

$$
\boxed{
\text{same word}
\neq
\text{same mathematical object}.
}
$$

## Principle B — Map Before Ontology

高層 phase claim 若要回接物理：

$$
\boxed{
x=\Pi(z)
}
$$

與：

$$
\boxed{
\Pi\Phi_{\mathrm{phys}}
\approx
\Gamma\Pi
}
$$

必須可定義、可測、可反證。

## Principle C — Benchmark Before Novelty

對 PH-5 / PH-6：

$$
\boxed{
\Delta S_\phi
=
S(M_\phi)-S(M_{\mathrm{typed}}).
}
$$

若無增益，phase 只是 nomenclature。

## Principle D — Mechanism Before Medical Inference

$$
\boxed{
B0\ \text{periodicity}
\not\Rightarrow
B1\ \text{phase}
\not\Rightarrow
B2\ \text{coupling}
\not\Rightarrow
B3\ \text{clinical relevance}.
}
$$

## Principle E — Preserve Provenance, Retire Claims

舊文件不刪除。退出的是 claim 的 current-canonical status，不是歷史紀錄。
