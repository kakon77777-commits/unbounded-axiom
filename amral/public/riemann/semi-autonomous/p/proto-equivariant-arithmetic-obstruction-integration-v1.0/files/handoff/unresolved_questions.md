# 未解問題與研究判斷點

## A. 理論

1. 區域相位塑形引理的平方像幾何假設，能否對所有相對緊有理矩形以有限細分統一滿足？
2. 支撐成本 $L_{\mathrm{sep}}(K;c,\varepsilon)$ 在 $K$ 接近實軸時的最佳下界為何？
3. 是否存在不等價於完整 Weil 正性的、可由有限算術資料生成的非平凡正錐？
4. 能否以無條件零點計數 majorant 對有限中間窗內所有未知偏軸零點給出足夠小的正洩漏界？
5. 最低偏軸高度縮減能否降低中間窗的最壞情況成本，而不偷渡唯一偏軸軌道假設？

## B. 計算

1. 算術正方向在 $q$ 增加時的塌縮，是目前 $24$-bump 基底的偶然，還是支撐固定下的普遍現象？
2. 增加基底維度能否使正方向數與軸消去數同步成長？
3. 分段線性 hat-spline 是否比平滑 bump 更適合作為最終證書語言？
4. 目標函數改為全域支配餘量後，最佳化問題是否仍有穩定可行區？
5. 區間化全窗 supremum 的計算成本是否可由自適應分帶控制？

## C. 形式化

1. 採用哪一個精確 Riemann–Weil 顯式公式版本作為唯一正規化來源？
2. 是否先在 Lean 中形式化有限 hat-spline 與 Fourier 閉式，再匯入顯式公式？
3. `mpmath` 區間證書應如何遷移到 Arb／FLINT 或核驗有理包絡？
4. 質數冪啟動清單如何附帶可獨立核驗的質數證書？
5. 無窮尾部如何拆成有限證書與可重用的一般殼層定理？

## D. 路線可否證

若下列任一現象被嚴格證明，應考慮將本路線降級為判定／證書框架：

1. 在可證算術正的全部非平凡函數族中，全域支配餘量必不為正；
2. 接近實軸的分離成本必定超過任何已知算術正性半徑；
3. 軸上零點正質量的無條件下界永遠超過可得偏軸負裕量；
4. 所需算術正錐的定義不可避免地等價於 RH；
5. 區域負函數的未知偏軸正洩漏無法由任何無條件總零點計數控制。
