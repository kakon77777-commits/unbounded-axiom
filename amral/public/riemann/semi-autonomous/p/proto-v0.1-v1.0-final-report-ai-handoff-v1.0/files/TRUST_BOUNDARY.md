- 搜尋候選；
- 選擇 interval target；
- 比較 methods；
- 找失敗方向；

浮點運算不可單獨支持：

- continuous universal positivity；
- universal counterexample；
- source-theorem coefficient；
- zeta occupancy；
- global RH conclusion。

## 禁止推論

- abstract interval certificate $\Rightarrow$ actual zeta theorem；
- scalar count $\Rightarrow$ arbitrary operator occupancy；
- synthetic occupancy $\Rightarrow$ actual zero presence；
- finite-family obstruction $\Rightarrow$ all-function impossibility；
- interval method failure $\Rightarrow$ point counterexample；
- local product box $\Rightarrow$ global critical-strip cover；
- one arithmetic-positive scalar $\Rightarrow$ general prime-side cone；
- any current artifact $\Rightarrow$ RH proof or disproof。
