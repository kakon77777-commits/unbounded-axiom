# 信任邊界

## 已證成

- 以 $90$ 位十進制定向捨入重算固定 Green 模型。
- 對 $58$ 個具名、彼此獨立的位置變量建立全稱區間盒。
- 在半徑 $89/50\,000\,000$ 上驗證 $60$ 維正區塊的 Neumann 可逆性。
- 驗證最後 $2\times2$ Schur 矩陣的兩個 Sylvester 下界。
- 驗證一個距中心 $10^{-3}$ 的精確有理角點仍嚴格正。

## 受條件限制的部分

所有結論都在繼承自 v0.7 的抽象偶夾持 Green 模型中成立。尾尺度、五帶係數、原子權重與核心原子視為父 witness 的固定輸入。v1.0 驗證輸入雜湊與父證書一致，但不重新證明它們的 zeta 面來源。

## 對失敗半徑的正確解讀

$1.8\times10^{-6}$、$10^{-4}$ 與 $10^{-3}$ 的失敗都是區間下界或候選逆的驗證失敗。它們不推出存在某個位置使算子非正。要得到點反例，必須固定一組位置並以獨立、嚴格的上界證明最小特徵方向非正；本包沒有這種結果。

## 浮點計算的角色

NumPy 只用來產生候選逆與候選解。這些候選被序列化成有限十進制，因此在驗證階段被當作精確有理數。最終真假只由定向區間運算決定。

父 v0.9 的浮點位置研究只用來：

- 比較可能的真實尺度；
- 選一組確定性的角點符號。

它不進入最大盒的全稱證明。
