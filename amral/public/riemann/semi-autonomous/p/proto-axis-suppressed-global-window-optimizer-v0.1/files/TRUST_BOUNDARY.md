# TRUST BOUNDARY

This package is a floating finite-dimensional diagnostic prototype.

Trusted or externally supplied components include:

- NumPy and SciPy linear algebra;
- SciPy SLSQP;
- mpmath constants;
- the stored first 50 zeta-zero ordinates;
- trapezoidal quadrature;
- floating eigenvalue and null-space computations.

Not certified:

- the stored ordinates as formal zero certificates;
- continuous target negativity;
- continuous control-window maxima;
- interval arithmetic for the arithmetic matrix;
- optimizer global optimality;
- any statement about all zeta zeros.

The package must not be cited as an RH proof or as a rigorous exclusion
certificate.
