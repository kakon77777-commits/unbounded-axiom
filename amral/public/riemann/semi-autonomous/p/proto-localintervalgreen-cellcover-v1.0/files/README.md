# RH Local Interval Green Cell Cover v1.0

本包是這一階段半自主黎曼猜想研究的技術收束節點。它把 v0.7 的固定有理原子證書與 v0.9 的極保守位置半徑，提升為一個可重播的 $58$ 維局部位置盒證書。

## 主結果

令五個頻帶中的 $58$ 個軸上位置各自獨立變動：

$$
x_j\in[c_j-h,c_j+h],\qquad
h=\frac{89}{50\,000\,000}=1.78\times10^{-6}.
$$

在繼承的偶、夾持 $H_0^2(-16,16)$ Green 模型、兩個結構約束及子參數 $\alpha=1$ 下，整個笛卡兒積盒內的抽象算子族都嚴格正。最大盒證書的關鍵下界為

$$
\|I-RA\|_\infty
\le 0.0275572505341<1,
$$

$$
T_{11}\ge 0.3305743170401>0,
\qquad
\det T\ge 6.69375118838\times10^{-5}>0.
$$

任何逐座標包含於最大盒內的閉有理子盒，都由同一證書向下繼承，因此形成下降封閉的覆蓋式證書族。相較 v0.9 的統一半徑 $2\times10^{-15}$，精確提升因子是 $890\,000\,000$。

## 邊界審計

- $h=10^{-8}$ 與 $h=10^{-6}$ 通過。
- $h=1.78\times10^{-6}$ 通過。
- $h=1.8\times10^{-6}$ 的最後 Sylvester 行列式區間下界為負，故證書不確定。
- $h=10^{-4}$ 與 $h=10^{-3}$ 的 Neumann 缺陷上界超過 $1$，故區間逆驗證不成立。
- 一個距中心 $10^{-3}$、採用父節點對抗符號的精確有理角點仍有嚴格正證書；所以大盒失敗不是點反例。

## 重要邊界

這是抽象 Green 模型中的局部位置量詞證書，不是實際 zeta 零點占用證書，也未完成顯式公式轉移，更不是 RH 的全域證明。所有相關旗標都保持為 `false`。

## 快速使用

重驗既有主證書：

```bash
PYTHONPATH=. python verify_cell_cover.py
```

跑快速單元測試：

```bash
PYTHONPATH=. python run_tests.py
```

完整重建、重驗、摘要與封裝前檢查：

```bash
PYTHONPATH=. python run_all.py
```

完整重建約需數分鐘，主因是七個 $62\times62$ 區間 Green–Gram 族的直接計算。
