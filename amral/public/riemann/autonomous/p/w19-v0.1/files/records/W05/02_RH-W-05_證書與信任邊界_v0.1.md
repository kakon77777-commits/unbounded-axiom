# RH-W-05：證書與信任邊界

**版本：** v0.1  
**用途：** 說明哪些部分是數學恆等、哪些部分是嚴格數值、哪些部分仍依賴軟體信任

---

# 1. 三層證書

本工程把結果分成三層：

## L0：數學規格

包括：

- 顯式公式；
- B-spline 卷積恆等式；
- 支撐區間；
- 素數項排除；
- 分部積分尾界；
- $p$-級數積分比較。

這些部分不依賴浮點運算。

## L1：嚴格數值生成

包括：

- 有理係數分段多項式；
- `Fraction` 區間運算；
- $\pi$、$\log$、$\gamma$ 的有理級數包絡；
- `Decimal.exp()` 的正確捨入值向外擴一個相鄰表示值；
- 固定十進有理網格上的向外捨入。

結果是完整有理上下界。

## L2：小型 exact verifier

`verify_matrix_certificate.py` 只做：

- 分子／分母解析；
- 區間方向檢查；
- $M_{11}=M_{22}$；
- 偶、奇模態的區間下界；
- Gram 行列式；
- 範圍聲明與 `RH_CLAIM=False`。

它不重新計算指數函數，也不執行浮點特徵值求解。

# 2. 信任基礎

本輪完整信任集合為：

```yaml
mathematical_sources:
  - Riemann-Weil explicit formula
  - B-spline convolution identity
  - integration by parts
  - p-series integral test
software:
  python: 3.13.5
  libmpdec: 2.5.1
  decimal_exp_contract: correctly rounded, ROUND_HALF_EVEN
local_code:
  - build_rigorous_matrix.py
  - verify_matrix_certificate.py
```

浮點二進制 `float` 不進入證明路徑。`float()` 只在 `VALIDATION.txt` 產生人類可讀的小數顯示。

# 3. 可接受宣稱

```text
CERTIFIED_POSITIVE_ON_THIS_2D_SUBSPACE
```

意思是：對固定的兩個 B-spline 基底所張成的二維實空間，Weil 二次型嚴格為正。

---

# 4. 禁止宣稱

以下全部不合法：

```text
RH_PROVED
WEIL_FORM_GLOBALLY_POSITIVE
ALL_SUPPORT_RADII_POSITIVE
NO_OFF_AXIS_ZERO_EXISTS
FINITE_MATRIX_IMPLIES_RH
```

# 5. 下一層信任縮減

若要移除 `Decimal.exp()` 的軟體契約，可新增一個完全自含的有理指數驗證器：

1. 把 $x$ 以二進範圍縮減成 $y=x/2^m$；
2. 用正項 Taylor 多項式包住 $e^y$；
3. 以幾何級數界包住餘項；
4. 進行 $m$ 次有理區間平方；
5. 比較其結果是否包含目前 Decimal 區間。

該工作登錄為：

```text
RH-W-05-FORMAL-BACKEND
```
