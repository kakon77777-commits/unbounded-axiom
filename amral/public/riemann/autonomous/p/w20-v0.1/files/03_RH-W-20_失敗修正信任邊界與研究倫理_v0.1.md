# RH-W-20：失敗、修正、信任邊界與研究倫理

## 1. 失敗不是旁註

Batch 01 將失敗視為第一級研究資料。最重要的案例包括：

1. 裸 $L^2$ 完成缺乏顯式公式所需的點值與連續性控制。
2. prime-3 七階新項不足以解釋近零模態。
3. 通道縮放 $\alpha$ 只是 gauge。
4. M/G 使用不同參數身分造成浮點假負值。
5. W-14 漏掉阿基米德支撐外尾，後由 W-15 修正。
6. W-06 缺少歷史 2×2 artifact。
7. 14 階 Hilbert exact 正定但 double eigensolver 回傳負值。
8. verifier、artifact、manifest 與 hash 同時串通時，自我認證封包不能建立外部真實性。

## 2. 主張分級

任何公開頁面都應分開：

$$
\text{探索性浮點觀察}
<
\text{區間／有理證書}
<
\text{形式化定理}
<
\text{全域 RH 結論}.
$$

Batch 01 到達第二層的一部分，也保存第一層與文件化數學推導；它沒有到達最後一層。

## 3. 外部信任根

SHA-256 只能證明「目前檔案與索引一致」。若索引、verifier 與檔案由同一攻擊者同步重建，內部檢查沒有未被控制的參照點。

後續推薦：

- 簽章 release digest；
- Git tag 與不可變 archive；
- reproducible build；
- Rust big-rational 第二實作；
- Lean/Coq 小型證書 kernel；
- 多站點 checksum mirror。

## 4. 平台倫理

AI 自主數學研究平台應顯示：

- 每個 node 的有限主張；
- 每個 node 沒有證明的事項；
- supersession 與 revision chain；
- verifier 信任契約；
- `RH_CLAIM=false`。

真正的自主研究不是自主發布成功宣言，而是自主接受可否證、可追溯與可修正的約束。
