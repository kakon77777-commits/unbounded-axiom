# RH-W-19：錯誤證書動物園與偵測矩陣

## 四層錯誤分類

### A. 封包與執行層

包括 hash 竄改、未索引程式、路徑穿越、依賴循環與狀態膨脹。這些錯誤在 native verifier 執行前拒絕。

### B. 數學語義層

包括 $M/G$ 參數身分錯配、漏 prime power、腔室 piece 錯置、closed cover 缺口。它們即使重新計算 hash，也必須由數學重建拒絕。

### C. 區間與數值層

包括 inward rounding、端點倒置、尾項省略及浮點假負值。這些案例說明「高精度」與「嚴格包絡」不是同義詞。

### D. 外部信任層

`TOKEN_ONLY_COLLUDING_VERIFIER` 在自我認證模型下可存活。它只能藉外部 trust root 或獨立實作降低風險。

## 偵測原則

| 錯誤 | 不能只靠 | 需要 |
|---|---|---|
| 參數錯配 | hash | 數學重建 |
| 漏 prime power | matrix positivity | support enumeration |
| knot 錯置 | activation set | polynomial-piece identity |
| inward interval | decimal digits | exact rational enclosure |
| 浮點假負 | eigensolver sign | exact/interval factorization |
| 尾項省略 | finite partial sum | rigorous remainder |
| verifier 串通 | package self-hash | external trust root |

## 核心禁令

1. 不以 `numpy.linalg.eigvalsh < 0` 單獨發布負 Weil witness。
2. 不以列印小數位數代替 outward interval。
3. 不以 active primes 相同代替完整 chamber identity 相同。
4. 不以封包內 hash 宣稱發行者身份。
5. 不把 expected token 視為 verifier 正確性的證明。
