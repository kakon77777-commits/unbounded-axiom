# RH-W-16：尺度曲率證書與計算架構

## 1. 本輪新增的計算負擔

RH-W-15 固定 $h$，只需要四個 $(d,\sigma)$ 角點。加入 $h$ 後，角點數增加為八：

$$
2^3=8.
$$

每個角點都需要重新計算：

- endpoint block；
- 常數 block；
- $P_2,P_3,P_4$；
- jump-resolved archimedean block；
- exact Gram；
- activation graph。

真正的時間瓶頸不是 $LDL^T$，而是八套阿基米德 jump／Laplace 資料生成。

## 2. 可重用資料層

本包把以下模組完整收錄，避免解壓後缺少相依檔：

- `weil_interval_core.py`；
- `rigorous_refinement_tools.py`；
- `mixed_order_core.py`；
- `mixed_order_jump_tail.py`。

`build_interval_taylor_tube.py` 也被保留為前一輪共用計算層，W-16 在其上加入可變 $h$ 的八角編譯器。

## 3. 證書與探索的分離

`build_three_parameter_tube.py` 負責：

1. 生成八角超越數區間；
2. 編譯 prime-power 腔室；
3. 生成二階曲率界；
4. 輸出大型 JSON 證書。

`verify_three_parameter_tube.py` 不重新生成超越矩陣，而只使用已儲存區間，重建：

- 三維餘項；
- knot margin；
- 八角 exact $LDL^T$；
- Gram 正定；
- 固定 witness 上界。

因此 verifier 路徑短於 builder，適合網站公開後快速重放。

## 4. 信任邊界

本輪證書使用：

- Python `Fraction` exact rational arithmetic；
- 文件化 outward interval arithmetic；
- `Decimal.exp` 外擴；
- 有理對數／平方根 enclosure；
- exact rational $LDL^T$；
- 獨立 mpmath 高精度抽查。

目前仍不是 Lean、Coq 或 Isabelle 核心驗證定理。正式標籤為：

```text
RIGOROUS_NUMERICAL_CERTIFICATE_UNDER_DOCUMENTED_SOFTWARE_CONTRACT
```

## 5. 下一個工程問題

三維盒已成立，但若下一輪直接跨越 prime-power 或 spline-knot 邊界，單一全域盒會失效。

所以 RH-W-17 將建立 chamber-aware subdivision：

$$
\text{大參數盒}
\longrightarrow
\text{邊界事件定位}
\longrightarrow
\text{子盒切分}
\longrightarrow
\text{逐盒證書與鄰接圖}.
$$

這也會迫使阿基米德資料從「每盒重算」升級為「按角點與 block-lag 快取」。
