# RH-W-20：二十輪研究地圖與有限數學結果總表

## 1. 三層結構

$$
\text{Macro GAP}\supset\text{Research Program}\supset\text{Certified Work Node}.
$$

原 47 GAP 是宏觀大陸；`RH-W` 在 Batch 01 中展開成一個獨立研究程序。二十輪不是二十個「證明步驟」，而是二十個具有不同語義的工作節點。

## 2. 節點類型

- `ANALYTIC_FOUNDATION`：函數空間與正規化推導。
- `STRUCTURAL_BRIDGE`：文獻與工程之間的邏輯橋。
- `PROTOCOL`：證書格式與條件性檢出邏輯。
- `NUMERICAL_MATRIX`：固定有限子空間上的 exact/interval matrix certificate。
- `STRUCTURAL_IDENTITY`：核階數、邊界正則性等符號結構。
- `PARAMETER_REGION`：連續參數盒上的一致證書。
- `CHAMBER_COVER`：事件面切分後的閉域覆蓋。
- `CERTIFICATE_BACKEND` / `ADVERSARIAL_AUDIT`：驗證與信任工程。
- `BATCH_RELEASE`：資料統合與交棒。

## 4. 狀態不是成敗二元值

- `VERIFIED`：完整包裝 verifier 可重放。
- `DOCUMENTED_DERIVATION`：有完整推導，但不是 proof-assistant theorem。
- `PROTOCOL_ONLY`：驗證協議存在，沒有目標負 witness。
- `SUPERSEDED_RECERTIFIED`：原推導被取代，結論由後續重證。
- `LEGACY_INCOMPLETE`：歷史 artifact 缺失，禁止綠化。
