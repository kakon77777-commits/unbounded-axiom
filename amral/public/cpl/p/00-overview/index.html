Critical-Line Proportion Ladder:從 Claude 67.25% 出發

從 Claude 2026-08-10 的無條件 67.25% 結果出發,研究 70%/80%/90%/99% 的可達條件。第一件事是語義鎖定:本專案的百分比不是黎曼猜想完成度,P_q 定義為 liminf 下,simple 且位於臨界線的零點比例下極限——即使達到 P₁(density-one),也仍然不等於 RH 的逐點全稱命題。核心證明結構可壓成:Weil explicit formula → finite Gabor compression → zero-side inertia → prime-side traces → rank-trace certificate。基準 flat-window certificate 在 λ=1 給出 H(1)=2/3;§7.1 對 window 最佳化後得到 c₁*=0.753296…,對應 2-1/c₁*=0.672500…,即 67.25%。特別區分兩個不可混淆的「天花板」:67.25% 是 window-optimisation/two-trace 子框架的極值(論文自陳 no window does better);68.185% 是 Remark 1.1 給出的更廣 bandwidth-one 類別上界,但本 Batch 尚未找到足以獨立重建該常數的完整推導,標成 OPEN-RECONSTRUCTION-01。文末給出 P0–P6 優先研究清單,並指出 Anthropic 官方 Lean companion repo(github.com/anthropics/zeta-23-lean)。
