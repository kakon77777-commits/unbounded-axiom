重建 Bandwidth-One 的 68.185% Ceiling

從一句 Remark 出發,直接進 Anthropic 官方 Lean companion repository 的 Zeta23/PairCeiling/ 讀出可驗證的 exact-rational 常數:LawN256.lean 記錄的 simple-point fraction 為 p0=0.681828687463832…,已非常接近論文 Remark 1.1 用的 0.68185。文件重建了三層機制——把離散近 CUE rows 提升到連續 certificate value 的 stability identity(Abel summation + 兩次分部積分)、把「近 CUE」量化成誤差界的 near-CUE law、以及把兩者合併成可直接引用的 signed ceiling 不等式。核心洞察是一個 information-indistinguishability obstruction:bandwidth-one pair observables 幾乎相同,不代表 simple fraction 會接近 1——`LawN256.lean` 本身就是一個刻意構造、平均 pair-correlation 幾乎完美模仿 CUE、但平均 simple-point fraction 只有約 68.18% 的機率律。文件同時老實記錄第一個缺口:官方 source 指定的外部證書 cert_N256_blk_b128m.json(SHA-256 已知)「available from the authors」,但公開 repo 目前並未包含它,所以完整的 configuration generation → exact rational LP solve → 外部 JSON 證書這條鏈暫時無法整條重跑。

p0 = 0.681828687463832… = 68.182868746383% — 包內文件自陳的階段性狀態,原樣照登。
