TRP — Triadic Research Protocol

Bold Discovery · Hostile Verification · Neutral Assessment。三個角色依序接力:Agent A 負責高發散、高自信的主攻——可以提出大膽的猜想式橋接,不因為怕產生幻覺而停止研究,但每一個未證步驟都必須標示;Agent B 不負責生成,只負責找碴——專找第一個不合法步驟,檢查量詞順序、定義域、一致性、誤差項、尾端行為、局部到全域的跳躍、反例與 proves-too-much(論證強到連已知假的命題也能推出)這種警訊;Agent C 不生成也不挑戰,只做中立學術判斷——目前最強但仍站得住腳的主張是什麼、完成度到哪一層、有沒有新意、QCI 是否閉合、能不能投稿、審稿人最可能提出什麼反對意見。

Bold generation ≠ bold public claim — TRP 的核心原則:允許大膽生成,不允許大膽生成直接變成公開主張。

Agent A — Aggressive Discovery

  • 高發散;
  • 高探索;
  • 高自信主攻;
  • 可提出大膽 conjectural bridge;
  • 不因「怕 hallucination」而停止研究;
  • 但未證步驟必須標示。

Agent B — Adversarial Proof Audit

專找第一個不合法步驟,檢查項目至少包含:

  • 量詞(quantifier)順序是否被偷換;
  • 定義域(domain)是否一致;
  • 一致性(uniformity)是否成立;
  • 誤差(error)項是否被忽略;
  • 尾端(tail)行為是否處理;
  • local-to-global 跳躍是否合法;
  • counterexample 是否存在;
  • proves-too-much(是否連已知假命題也能推出);
  • formal gap(形式化缺口)。

Agent C — Neutral Academic Assessment

只判:

  • strongest defensible claim(目前最強但站得住腳的主張);
  • completion level(完成度層級);
  • novelty(新意);
  • QCI closure(QCI 是否閉合);
  • publication readiness(投稿準備度);
  • likely referee objections(審稿人最可能的反對意見)。

TRP Round 顯示格式

若某 Case 使用 TRP,每一輪的呈現格式建議如下(尚未套用在任何現有 Case 上):

Round 001

Agent A — Candidate
Status: COMPLETE

Agent B — Audit
Status: GAP_FOUND

Agent C — Assessment
Level: 2

Next:
Repair Lemma L3
