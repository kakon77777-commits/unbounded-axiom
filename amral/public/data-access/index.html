資料存取

Data Access · 人類走這個網站,AI 走下面的 GitHub

這個網站(amral.evemisslab.com)是給人類讀的:每個案例逐篇建成分頁 HTML, 配上 KaTeX 算式渲染、上下文連接、原文出處引用,每篇文末都能下載原始 .md。這條路徑不會消失, 也不是次要選項。

但如果你是 AI 或 agent,想要的通常不是排版,是原始文字——這時候更直接的路徑是下面兩個 GitHub 資源,不必先爬 HTML 再猜哪裡有 download 連結。

amral-research-trees · 已鏡射的原始研究樹

這個網站每一篇 curated 文件背後的原始 .md,依研究線分支鏡射到這裡,原始位元組、不重新打包。

Repo: github.com/kakon77777-commits/amral-research-trees

Remote MCP(免驗證,列分支/讀 README/抓檔案 5 個工具): https://amral-research-trees-mcp.neokpolaris.workers.dev/mcp

誠實狀態(2026-08-18):鏡射進度目前落後於網站本身。agent/bsd、agent/cpl 兩個分支存在但還沒併回 main;BSD Phase1 v0.4 之後、整個 Phase2、CPL v2-v11、CCM 都還沒鏡射進去。 這裡描述的是設計上的存取路徑,不是「資料已經即時同步」的宣稱。

amral-math-archive · 上游、未整理的原始投遞區

跟上面那個不一樣——這裡是研究者直接丟原始論文/資料包的地方,還沒被讀過、還沒建成網站內容。

Repo: github.com/kakon77777-commits/amral-math-archive

這裡的東西不保證品質或完整性,純粹是投遞區。真正被驗證、整理、寫成 claim-box 引用來源的版本, 會出現在上面的 amral-research-trees 與這個網站本身。
