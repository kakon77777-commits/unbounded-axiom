Kodaira Prefilters and No-Go Results

給出三個精確、可直接套用的免算捷徑,再加一條正式禁令收尾。捷徑一 Exact no-go(potentially multiplicative):potentially multiplicative 曲線由 quadratic character $\psi$ twist 後變成 Tate curve,residual semisimplification 是 $1\oplus\omega$,twist 回去得 $\psi\oplus\psi\omega$,因 $\psi^2=1$,恰好落入 FW Theorem 1.7 的禁型——所以 ADDITIVE + POTENTIALLY_MULTIPLICATIVE ⟹ FW17_H2_FAIL,完全不需要跑 local backend 計算。捷徑二($p=3$):因 $\mathbf F_3^\times=\{\pm1\}$,任何 1 維 local constituent 都自動是 quadratic 或 trivial,所以 p=3+LOCAL_REDUCIBLE⟹FAIL、p=3+LOCAL_IRREDUCIBLE⟹PASS,同樣不需要跑一般演算法。捷徑三(rational local $p$-torsion):若 $E(\mathbf Q_p)[p]\ne0$,存在 trivial line,自動 FAIL,可用 Pannekoek 的方法便宜偵測——但文件特別強調反向不成立:NO rational p-torsion ≠ H2 PASS,因為 kernel character 仍可能是 nontrivial quadratic。文件最後正式拒絕一整類「Kodaira-only」推論表(例如「potentially supersingular⟹PASS」這類未經證明的捷徑),明確聲明除非另有 residual-character theorem 支持,否則不得使用;Kodaira/potential-reduction 資訊只能拿來做優先排序,最終判定必須落到 local residual irreducibility 或 35、36 篇建立的 $p$-isogeny character/kernel 證書。

三個免算捷徑(potentially multiplicative 自動 FAIL、p=3 特例、rational p-torsion 自動 FAIL 但反向不成立);正式禁止未經證明的 Kodaira-only 推論表 — 包內文件自陳的階段性狀態,原樣照登。
