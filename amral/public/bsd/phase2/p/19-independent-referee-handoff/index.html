Independent Referee / Local Agent Handoff

v0.3 系列的收尾文件,目標寫得極為明確:不要再搜尋更多 curves,先嘗試推翻 696.e1 family theorem。設計六位獨立 referee,每位針對論證的不同環節,姿態是「找漏洞」而不是「確認」:Referee A 逐項重驗 Theorem 2.14 的 base 條件與 symbolic $q\in\mathcal P$ 的分裂條件,輸出 PASS/FAIL;Referee B 只使用 Banwait–Huang Remark 2.10 明確允許的 non-semistable 替代方案重驗 odd ordinary/additive 分支;Referee C 優先使用 FW Theorem 1.1 較強但較簡單的 sufficient hypotheses,而不是自行改寫最一般的 Theorem 1.7,避免「自己批改自己的作業」;Referee D 證明 period 不整除 Manin-period discrepancy,且明確要求優先引用已發表的 Manin-constant 結果,不依賴未發表的 Edixhoven remark;Referee E 獨立從頭重算整個 Chebotarev 計算(判別式、Galois group、resolvent、fiber product 次數、conjugacy class 大小、密度);Referee F 寫程式對 $q<10^7$ 掃描所有 $\mathcal P$ 質數找反例,但文件明確自我提醒:數值 sweep 不是 theorem proof,只是找 implementation/case bug。文件最後給出清楚的停止規則:若 Referee A-E 全部 PASS,升級為 DERIVED THEOREM / PREPRINT CANDIDATE;若任何一項 FAIL,凍結擴張,退回那個確切失敗的引理。

六位對抗式 referee,姿態是「先嘗試推翻」;C/D 兩位特別要求優先用較弱但已發表/較簡單的來源,避免自我批改;F 明確聲明數值掃描不是證明;A-E 全過才升級,一項失敗就退回確切引理 — 包內文件自陳的階段性狀態,原樣照登。
