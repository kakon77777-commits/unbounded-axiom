本地多 Agent 交接提示

把 Phase 1 拆給六個角色:Agent A 命題稽核者(只用標準外部數學建立 BSD-W/BSD-F/BSD-S 的 theorem dependency DAG,禁止把 rank equality 等同 full BSD、把 analytic Sha 等同 actual Sha、用 Wikipedia 當核心 theorem source);Agent B Banwait–Huang 重現者(重現 arXiv:2601.16044 的演算法,先跑作者樣本再跑 conductor≤500000,若 paper criterion 有任何無法從 LMFDB/Sage/Magma exact 決定的欄位,標 unknown,不得猜測);Agent C 證書 schema 工程師(實作並驗證 bsd_curve_certificate.schema.json,把 numeric evidence、rigorous computation、external theorem、conditional theorem、actual proof 明確分開);Agent D rank-2 牆分析者(以 389.a1 為中心,逐項審計 r_alg、r_an、Ω、Reg、c_p、Sha、L^(2)(1)/2! 各自是如何算出、是否 rigorous、是否有 theorem 支持);Agent E 對抗性裁判(對所有輸出找循環 BSD assumption、numerical-to-proof leap、finite-to-global leap、p-part-to-full leap 等,輸出必須是 PASS/FAIL/OPEN,不能只寫一般建議);Agent F 內部理論隔離(審計 Neo.K 舊格點/PRC 稿與 BSD 的關係,只允許輸出可翻譯成標準 lemma 的部分、循環或未定義部分、需要的新 proof obligations,禁止直接把內部公理帶進 external main proof)。這個六角色交接結構本身就是TRP精神的一個真實案例——生成、對抗式審查、中立判定分開執行,只是這裡切得比 TRP 的三角色更細。
