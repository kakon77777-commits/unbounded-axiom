Phase 1 Agent 實驗規格:Certificate Atlas + Twist-Family Reproduction

目標不是「對幾百萬條曲線計算一個 BSD 比值」,而是對完整有限域(N_E<500,000,LMFDB 完整覆蓋)中每個 isogeny class,生成 theorem-applicability、證書層級與未閉合項。工作流分五步:Ingest(抓取 LMFDB/Cremona label、a-invariants、rank、regulator 等)、Evidence typing(每欄位標 exact/rigorous_computation/numerical/BSD_inferred/unknown)、Theorem router(逐條檢查 GZK、BSTW zeta-element、Banwait–Huang、main conjecture、p-converse 等)、Certificate level(依 C0–C10 標記)、Wall classification(未閉合原因限定受控詞彙)。測試分三組:R0(rank 0,測 weak BSD 已知定理與 p-parts)、R1(rank 1,測 Heegner point/Kolyvagin applicability)、R2+(rank≥2,不求全面閉合,只找 theorem coverage 突然下降的位置)。第一個 rank-2 樣本是 389.a1(LMFDB 給 r_alg=r_an=2,數值首項吻合),但 Agent 任務不是再算一次,而是逐項回答證書來源、generators 是否 saturated、Sha_an=1 是否 actual proof、哪些 p-parts 已知。第一個 family reproduction 是重現 Banwait–Huang 2026 演算法,先跑作者樣本再跑全 conductor≤500,000,對 discrepancy 做 adversarial audit。成功條件明確不要求新 BSD 定理,只要求完整 schema、至少三類曲線的證書、演算法可重現、每個結果能區分 evidence/theorem、找到高秩前三大共同瓶頸。

實驗規格 · Benchmark:N_E < 500,000,樣本曲線 389.a1 — 包內文件自陳的階段性狀態,原樣照登。
