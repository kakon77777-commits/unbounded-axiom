BSD Certificate Globalizer

建立一個不會因為「大多數曲線已認證」就吞掉單一未認證曲線的研究控制量——它忠實於認證狀態,不是直接忠實於 BSD 真值。以 conductor、isogeny label 建立可計算枚舉 ℰ={E₁,E₂,…},固定目標證書層 ℓ*∈{C6,...,C10},第 k 輪後令 H_k(ℓ*) 為尚未達到 ℓ* 的曲線集合。定義 Faithful Unresolved Mass 𝔅_k(s;ℓ*)=Σ_{i∈H_k} i^(-s)(s>1):任何一個固定未認證 class 都留下正質量,對無限枚舉,若證書系統單調,𝔅_k→0 表示每個固定 class 最終離開未解前沿。但即使 𝔅_k→0,也只表示採用的證書系統逐項覆蓋了枚舉域,要真正推出 BSD 還需要五個額外條件:每個證書 sound、target claim 確實等於 BSD component、枚舉覆蓋所有 E/ℚ、證書生成不是拿 BSD 當 oracle、對所有曲線真正達到有限 stage。可分別定義弱 BSD backlog、Sha 有限性 backlog、強式公式 backlog 三個獨立維度,避免一個總分掩蓋「rank 已證,但 Sha 未閉合」這種情況。
