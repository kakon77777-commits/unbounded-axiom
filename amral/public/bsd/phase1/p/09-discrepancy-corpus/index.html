官方 Discrepancy Corpus

官方 repository 保存了一份專門的診斷報告,對四條曲線——62a1、66b1、105a1、141c1——逐 predicate 解釋為什麼現行 Algorithm 1 拒絕它們。這四條曲線共同通過了 semistability、isogeny exclusion、ramification、optimality、rank-zero gate、$E'$ 的 2-descent gate 與現行 $\operatorname{BSD}(E,2)$ gate,但各自在四個具體 predicate 上失敗:$\operatorname{ord}_2 L^{\mathrm{alg}}=-2$(CLZ20 要求 $-1$)、$E'(\mathbb Q)_{\mathrm{tors}}$ 的 2-撓點結構是 $(2,2)$(不符合所需的 cyclic 條件)、$f'(x_0)$ 是有理數的平方、$\mathcal S$ 非空性 gate 失敗。文件把這份資料明確定位為 theorem-router 對抗式回歸語料庫,並給出一條精確、可直接引用的紀律:未來若某個版本突然接受這四條曲線,第一個貼上的標籤應該是 REGRESSION?,不是 NEW BSD BREAKTHROUGH!——這正是把 08 篇「reason=OPEN,不猜測」的紀律,反過來用在「意外通過」的情境上。
