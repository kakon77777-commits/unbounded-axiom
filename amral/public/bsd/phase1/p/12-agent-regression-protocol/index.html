Agent Regression Protocol

規定每個 Agent 在修改 theorem router 之前,必須跑三層測試:Layer A(目前 12 條正向 fixture)、Layer B(僅舊版才有的 13 條歷史回歸曲線)、Layer C(官方 discrepancy 四條曲線)——這三層剛好對應 08、09 兩篇已建立的語料庫。輸出格式統一成一份 JSON,包含 curve、decision(PASS/FAIL/UNKNOWN 三態,不是二元)、first_failure、all_failures、evidence、code_version、semantic_version 欄位。文件核心是四道「認知防火牆」,直接點名四個最容易犯的偷換概念:analytic Sha = 1 不等於 Sha is trivial;rank = 0 不自動等於 rigorous analytic rank 0;2-descent 維度與 analytic valuation 數值相同,不自動等於 $\operatorname{BSD}(E,2)$ 已證;timeout 必須標 UNKNOWN。最後一條紀律同樣重要:若新版本只改善 runtime、cache、batching 或 output formatting,標記 ENGINEERING ONLY,不計為 BSD 數學進展——這條規則正是為了防止把純粹的效能優化包裝成研究突破。

三層回歸測試(12正向+13歷史+4discrepancy);四道認知防火牆;純工程改動標 ENGINEERING ONLY — 包內文件自陳的階段性狀態,原樣照登。
