Phase 1 下一個最低成本 Gate

v0.4 系列的收尾文件,把 18-20 篇累積的 500K 規模觀察收斂成一份三段式最低成本執行策略。Gate A 是 delta-only base verifier:輸入舊 accepted list 加上 a3/isogeny_degrees 兩個便宜欄位,目標精確重現 $40{,}749\to36{,}687$。Gate B 是 twist JSON parser diff:直接物化 old/current 兩份 twists_of_ec_labels_500k.json,計算 removed base keys、stable base keys、有 twist 變化的 stable curves、僅因 $\gcd(\cdot,3N)$ 而移除的 twists、僅因刪除舊 disc gate 而新增的 twists、以及同時受兩種效應影響的曲線,共六類。Gate C 則是只有當 A、B 都與官方 repository 目前輸出完全一致時,才重跑全部昂貴的 Sage descent。文件把整個策略的理由收成一句可直接引用的箴言:完整 Algorithm 1 官方 paper runtime 本身約十幾分鐘,其實不算昂貴,真正昂貴的是研究語義錯誤的返工——delta-first 策略可以先確認「我們理解的是同一個 theorem version」,再投入 full proof-engineering,而不是反過來。

三段式策略:Gate A(delta-only,cheap)→ Gate B(twist JSON parser diff,六分類)→ Gate C(僅兩者吻合才 full Sage replay);真正昂貴的是語義錯誤的返工,不是 runtime — 包內文件自陳的階段性狀態,原樣照登。
