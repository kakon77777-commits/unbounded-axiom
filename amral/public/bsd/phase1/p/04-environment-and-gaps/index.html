Algorithm 1 的執行環境與尚缺項

完整重跑 Algorithm 1 需要 SageMath、本地 LMFDB PostgreSQL 資料庫、lmfdb Python package、pandas/numpy、PARI 2-descent、mwrank、Sage native 2-isogeny descent,以及足夠的記憶體與本地資料——本輪環境不具備這些條件。文件直接列出本輪「沒有做」的項目:沒有連線本地 LMFDB PostgreSQL、沒有執行 Sage、沒有執行 2-descent、沒有重掃 conductor<500000、沒有獨立證明官方的 36,687 curve count,因此明確聲明不能寫「Full Algorithm 1 independently reproduced」。取而代之,本輪完成的是六項替代工作:逐條拆解 theorem conditions、讀取目前官方 implementation、審計證書強度、取得官方小樣本 fixtures、獨立重現 Algorithm 2、建立下一輪的 Sage execution plan。文件給出 Phase 1 v0.2 的最低環境測試計畫:先在 conductor<150 跑 Algorithm1.py,預期輸出 12 條 base curves,再用這批曲線跑 Algorithm2.py,比較 curve labels、來源 branch、twists、檔案 SHA、pass/fail metadata 是否與官方完全一致——只有在這個小樣本完全吻合之後,才允許進入 500K 全規模重跑。

本輪不能寫「Full Algorithm 1 independently reproduced」——完整列出六項尚缺工作與小樣本先行計畫 — 包內文件自陳的階段性狀態,原樣照登。
