Semantic Version Changelog

文件用一句話定住整個 v0.2 系列的核心動機:theorem-producing code 必須額外保存「數學語義版本」,不能只看 Git commit——兩個 commit 之間即使只差一次提交,數學意義上的證書強度也可能整個改變(這正是 14 篇即將展示的具體案例)。文件列出八項需要監控語義漂移的具體項目:$p$-isogeny 與 $a_3$ gate 的定義是否改變、$\gcd(d,3N)=1$ 這條 twist 條件是否還在、$\operatorname{BSD}(E,2)$ 目前被當成必要條件還是完整證書、$E'$ 的 $\Sha[2]$ 驗證方式、$\mathcal S$ 非空性判準是 deterministic criterion 還是退回 bounded search、testing flags 的狀態、timeout 目前是標 FAIL 還是 UNKNOWN、algebraic rank 與 analytic rank 是否仍然分開存欄。文件把整篇的核心原則收成一句可以直接引用的箴言:code version ≠ theorem semantics version——版本號可以完全沒變,但底下的數學語義已經漂移;也可能只差一個 commit,數學語義卻已經整個不同。

code version ≠ theorem semantics version(核心原則) — 包內文件自陳的階段性狀態,原樣照登。
