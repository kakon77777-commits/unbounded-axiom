# Fourier-18 雙池與 B-spline 保留審計

## 1. 動機

第 7 輪顯示兩種不同空間攻擊：

- 分散多葉片型；
- 局部深穿透型。

第 8 輪不再只沿單一母系擾動，而建立：

1. 分散母系 Fourier-18 池；
2. 局部穿透母系 Fourier-18 池；
3. 非 Fourier 的平滑 B-spline 保留池。

## 2. 搜尋結果

分散母系池共有：

\[
24
\]

\[
\boxed{

}
\]

局部母系池共有：

\[

\[

=

\]

B-spline 池共有：

\[
20

\[
e_{\mathrm{spline}}
=
0.000021419854.
\]

本批 B-spline 候選沒有留下 \(10^{-3}\) 以上的穩定外露。

## 3. 代理排序失效

快速搜尋使用從母曲線繼承的局部放置。

但完整全域合同搜尋後，候選排序大幅改變。

最終最強曲線並不是局部代理排名第一者。

因此：

\[
\boxed{
\text{非凸容器中的曲線排序，不能以單一繼承配置作證書。}
}
\]

局部清距或局部外露代理只能負責產生候選；最終必須重新求：

\[
\inf_{g\in E(2)}
\mu_2
\left[
(gT_\rho(\gamma))\setminus C
\right].
\]

## 4. 雙池沒有形成二元封閉

兩個 Fourier-18 母系都仍留下正外露曲線。

但分散母系的最佳值略高於局部母系：

\[
e_{\mathrm{dist}}
>
e_{\mathrm{loc}}.
\]

所以容器並未只剩一種薄弱模式。

相反地，它仍可被不同頻譜母系以不同空間型態突破。
