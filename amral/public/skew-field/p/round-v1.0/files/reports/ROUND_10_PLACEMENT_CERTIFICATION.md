# 非凸合同放置器的假 hard case 問題

## 1. 異常候選

Fourier-22 混合母系的一條候選，在低預算合同搜尋中得到：

\[
\widetilde e
=
0.040938380334.
\]

這接近單體管狀面積的一半，看似是極強 hard case。

## 2. 高預算重算

使用：

- 原向與鏡像分支；
- 每分支多個 differential-evolution 種子；
- 更密集族群與迭代；
- Powell 局部細化；
- 高解析完整管狀外露重播；

得到：

\[
\boxed{
e
=
0.000225741207.
}
\]

低預算結果高估約：

\[
\boxed{
181.4
\text{ 倍}.
}
\]

## 3. 結論

在非凸容器中，外露泛函對剛體配置具有大量離散凹槽與局部分支。

因此：

\[
\boxed{
\text{生成器找到的 hard case}
\text{ 必須先通過 }
\text{放置器反證}.
}
\]

最低要求應包括：

1. 雙手性；
2. 多種子；
3. 低解析篩選與高解析重播分離；
4. 對異常高值追加搜尋預算；
5. 保存次佳放置分支與收斂差距。

第 10 輪真正穩定的保留候選不是該混合曲線，而是分散母系 Fourier-22。
