關於 AMRAL

About AMRAL Research Lab

AMRAL 是一個用於人類主導、半自主、自主與多 Agent 數學研究的可重播研究實驗室。 它最初由 RIITG、RAB、KCPE 與 AMRAL 自主研究循環發展而來——現在統稱為 AMRAL-Core—— 但平台本身不要求所有研究案例使用同一方法論。不同 Case 可以採用 AMRAL-Core、直接搜索、計算探索、 三 Agent 研究協議(TRP)、QCI 定量閉合、形式化驗證,或其他未來研究方法。

五個彼此獨立的軸

每一個研究 Case 由以下五個獨立的軸描述,不是單一固定流程。

軸 A

Case

研究什麼?黎曼猜想、Erdős 系列猜想、WOWII 圖論猜想等。

軸 B

Methodology

如何產生、展開與收斂研究路徑?可以是 AMRAL-Core,也可以是 direct search 或未來方法,也可以完全不用固定方法論。

 軸 C

Protocol

AI / 研究角色如何協作?目前為 TRP(Triadic Research Protocol),未來可擴充。

 軸 D

Autonomy Mode

誰掌握研究方向與排程?human-led / semi-autonomous / autonomous / multi-agent-autonomous。

 軸 E

Validation

研究結果如何被合法化、定量閉合與驗證?QCI、對抗式審查、盲測重推導、形式化證明等。

名稱語義

AMRAL — 上位概念,Research Lab / Platform,這個網站的全部內容。

AMRAL-Core — 原始方法論(RIITG + RAB + KCPE + 九步研究循環),Methodology 軸下的其中一個選項,不是全站強制流程。

AMRAL Case — 站內個別研究案例,例如黎曼猜想、P/NP 對偶預演。

不再是 AMRAL methodology = 這個網站的全部內容 這個等式。

共同要求

AMRAL 的核心要求不是「所有研究走同一條路」,而是研究過程必須:

1

Traceable

可追蹤

2

Replayable

可重播

3

Falsifiable

可否證

4

Revisable

可修正

5

Verifiable

可驗證

失敗與被取代的路線不刪除;有限計算不冒充無限證明;候補猜想不寫成 active proof project——完整規則見下方交接文件原文。
