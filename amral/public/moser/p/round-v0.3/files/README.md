# Moser Skew Lab v0.3

半自主研究第 3 輪：接觸帳本逆向生成的第一版。

## 結果

- 三連桿基準：0.998574374711
- 最佳五連桿：0.998754371668
- 最佳七連桿：0.998674157956
- 五對三增益：1.799969565222e-04
- 七對五增益：-8.021371146472e-05

## 主要結構

最佳五段與七段候選皆形成：

- 兩端點共同接觸斜邊；
- 一個內部頂點接觸左邊；
- 一個內部頂點接觸底邊；
- 鏡像對稱，無手性假警報。

七段未超越五段，顯示新增線段大量退化為近平行子段。

本封裝不構成 Moser 問題的新上下界。
