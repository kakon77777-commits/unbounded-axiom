# Moser Skew Lab v0.7

半自主研究第 7 輪：折線—曲率弧混合族。

## 可靠控制排序

1. 離散事件五連桿：0.998903757132509
2. 解析等高常曲率翼：0.998862397495093
3. 最佳分段啟發式候選（m=6）：0.998839177646286

## 核心判定

常曲率平滑化仍低於離散事件骨架：

$$
4.135963741603e-05.
$$

這支持「曲率集中具有可測價值」的工作命題，但不代表所有平滑曲線都較差。

## 重要審計

統一啟發式搜尋未能在 $m=2$ 重現已知事件控制，因此所有分段結果只視為有限搜尋候選，不能視為各族全域最優。

本封裝不構成 Moser 問題的新上下界。
